# 学业测评机位助手

## 0.2.6：默认安装到 C 盘，修复新版网页认不出助手

2026-10-29 本机构建，2026-10-30 已随平台 1.30.63 热替换发布（下载文件已更新为 0.2.6）。两处变更：

1. **默认安装目录改为 `C:\SchoolSeatHelper`**。机房同传/还原通常只覆盖 C 盘，装到 D 盘不会随镜像下发。C 盘根目录不可写时仍回退到当前 Windows 用户的本地应用目录。老版本装在 D 盘的同一台电脑首次运行 0.2.6 时，会把 `seat-helper.dat` 与 `platform-url.txt` 自动复制到新目录，保留原设备关联；原目录不删除，便于回退。
2. **网页探测不再写死版本号**。1.30.60 前端只接受助手 `0.2.3/0.2.4`，导致已装 0.2.5 的电脑全部显示“机位未关联”。前端改为按最低版本 0.2.3 比较，后续助手小版本升级不会再被网页拒绝；该修复须与助手 0.2.6 配套发布。

安装包、自启动项、桌面快捷方式和本机关联都在 C 盘时，老师只需在母机装好并完成关联后再制作同传镜像；只装单机、未更新镜像时，同传后不会保留。客户端 53 项回归通过，新版本清单 `dist/manifest.json`。网页端 1.30.61 已能识别 0.2.5 及以上版本；0.2.6 主要解决默认安装目录，已装 0.2.5 的电脑需退出助手后重新下载安装一次才会迁到 C 盘。**0.2.5 内部固定使用 `D:\SchoolSeatHelper`，仅把文件夹复制到 C 盘不会改变数据目录，不能手工迁移；必须运行 0.2.6。**

## 学生使用

1. 登录学校平台，在学生首页点击“下载机位助手”。
2. 直接运行下载的 `SeatHelper.exe`，无需填写接口地址、注册码、网页地址或安装目录。
3. 自动安装后弹出“安装与运行状态”，核对实际安装目录、自启动与桌面快捷方式结果；C 盘首选目录不可写时明确显示回退到当前用户目录，不静默冒充安装成功。
4. 助手自动获取内网IPv4和电脑信息，打开原网页登录关联。已登录可直接关联；未登录仍使用原学生账号，不增加客户端账号。
5. 查看“本机关联：已保存”后，点击“完成，后台运行”。关闭结果窗口也仅隐藏，助手仍留在右下角托盘；托盘“退出助手”才停止运行。

下载到桌面不影响安装位置。新版先完整复制程序再从安装目录启动，保留原 `seat-helper.dat`；快捷方式和自启分别执行并报告，任一失败不会阻断另一项。若旧助手已运行，先按提示从托盘退出旧版，再双击新版更新。自启动是当前Windows用户登录后运行，并非登录前的系统服务。

安装优先 `C:\SchoolSeatHelper`，没有写权限时使用当前Windows用户的本地应用目录。创建“学业测评平台”桌面快捷方式和当前用户登录自启项。日后点击快捷方式关联当前学生；直接打开网页仍正常上课。

托盘可打开平台、查看安装与运行状态、重新自动关联或退出。结果窗口可打开安装目录、重试自启动设置。配置损坏时正常运行重新自动关联，同校有效设备保留原设备记录和教师命名；已被撤销电脑不能靠重新下载自动恢复，普通网页登录仍可用。

## 教师管理

当前授权课堂“机位明细”显示学生、内网IP和电脑记录，点击“设置机房/机位”填写名称。首次自动登记显示“未分配机房”和临时电脑名称。再选择机房、点击“确认本班常用机位”保存长期基准，学生无需填写这些信息。

调座须再次明确确认。缺席、未识别、同机多账号和占用他人的保留机位不覆盖原绑定；历史课堂不能修改。IP变化不等于换电脑，断线不能用来判断学生违规。

## 管理员与服务端

复用 `sql/classroom_experience_seat_helper_v1.sql` 三表，自动关联没有新增结构迁移。新部署默认关闭；设置 `seat-helper.enabled=true` 和真实 `seat-helper.client-path`，在管理员菜单开启学校、填写HTTP/HTTPS网页根地址，如 `http://10.52.1.130`，不加 `/student/index` 或 `/prod-api`。HTTPS不是安装前置条件。

Windows .NET Framework4环境运行 `build.ps1` 生成程序和SHA-256清单，无新依赖。鉴权下载在EXE尾部附带公开站点根地址，不包含账号、密码、登录令牌或注册码；下载包整体哈希不同于原始程序，主体应与编译清单一致。程序未签名，系统运行提示按学校规则处理。

可按学校规则分发程序，不能复制已注册的 `seat-helper.dat` 到别的电脑。`--configure` 仅保留高级人工注册码配置兼容入口，普通启动不进入该表单。

## 保存、断线与还原卡

本机凭据DPAPI加密，服务器仅存密钥哈希。自动配对五分钟有效，学校由原网页登录确定；设备密钥只由持有独立随机轮询凭据的客户端领取。领取结果两分钟有效，保存成功后确认。日常打开链接一分钟且单次消费，网页及时清除片段。

设备每30秒上报IPv4，75秒无心跳即离线；网页会话90秒失效，学生布局在Python、物联等子页继续续期。助手异常打开公开普通网页地址，平台自身不可达不能保证页面可用。

**老师只需在首次部署时完成一次基线操作；不要每节课让学生重新下载。**

1. 按机房现有还原软件流程进入维护状态，确认目标安装目录能纳入基线或被保留。
2. 在实际学生使用的Windows用户下运行新版，检查安装位置、自启动和快捷方式结果。
3. 学生登录完成关联，确认窗口显示“已保存”、教师机位明细能看到该电脑内网IP。
4. 在还原软件中保存/更新基线（具体按钮按学校软件，不由助手自动操作）。不要把某台已关联的凭据文件复制到其他电脑。
5. 进行一次真实重启还原并登录同一Windows用户：不再运行下载副本，检查托盘、自启动、快捷方式、教师端连接；通过后再批量推广。

安装目录、用户注册表、自启项、桌面快捷方式、DPAPI密钥和机器标识须纳入同传镜像或还原基线。必须完成“运行关联→更新镜像/基线→同传或重启→快捷方式→教师核对”的现场验证。Windows10、极域、还原卡、自启和镜像克隆仍需真实机房验收，开发机测试不替代现场条件。

## 撤销与卸载

管理员撤销立即使旧凭据失效，原长期基准保留。需要重新启用由管理员人工处理，不自动绕过撤销。卸载先退出托盘，再删除当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\SchoolSeatHelper` 项和桌面“学业测评平台”快捷方式，最后删除管理员确认的安装目录。仅删客户端不撤销服务器记录。

关闭学校或全局开关停止助手能力，正常教学继续。
