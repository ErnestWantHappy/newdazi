## 背景与备选方案

## 决策

1. 移除当前项目AOCI接入、专属规则、正式索引/状态及本机安装目录，不自动重装；保留历史决策入口。用户后续明确要求不保留恢复备份，已手动删除并由代理复核。
2. `AGENTS.md` 管操作与授权，`PROJECT_CORE.md` 管当前环境/焦点/验证/风险，架构索引管资料入口，专题保存需求/设计/任务/ADR和详细验收。
3. 接管按固定三个入口后定向读取源码和必要调用链；高风险修改继续核对真实数据边界和测试。核心文档约150行以内，旧状态完整归档，避免启动必读内容持续膨胀。

- 省去完整索引加载、维护及专属长规则；文档更新仍由开发者负责，源码/目标环境证据优先，不能把文档视为自动准确的运行实况。
