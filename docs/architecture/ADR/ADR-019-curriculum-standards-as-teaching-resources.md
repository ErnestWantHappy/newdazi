# ADR-019：课程标准作为独立教学资料区

- 日期：2026-11-09
- 状态：已采纳并上线（1.30.87）
- 关联：[电子教材任务](../../../contexts/textbook-module/tasks.md)、[1.30.87验收](../../../contexts/textbook-module/release-1.30.87.md)

## 背景

电子教材原先只有小学、初中13册教材，按年级/学期分组。用户要求同时上架普通高中3册教材和两份信息科技课程标准。高中教材仍可按册、单元、课次阅读；课程标准是跨年级的指导文件，没有教材课次语义。

若把课标塞进 `biz_textbook_book/section`，会生成不存在的课次，污染目录、课程绑定和阅读器定位；若只给一个PDF下载链接，又无法逐页在线阅读，不符合教师备课查找习惯。

## 备选方案

1. 课标伪装成“无课次教材册”：能复用页面和阅读器，但书架语义不自然，容易误绑定课程，不采用。
2. 只提供PDF下载：实现简单，但失去在线逐页查找，不采用。
3. 独立资料表 + 独立书架分组：教材仍是教材，课标仍是标准，各自使用合适的阅读/预览方式，采用。

## 决策

- 高中教材复用既有四张教材表和阅读接口，`stage=senior` 仅作展示，不参与中小学课程绑定。
- 新增 `biz_textbook_standard`，以 `standard_key` 唯一保存课标元数据、原PDF路径、预览路径、字节数、SHA-256、适用学段和上下架状态。
- 课标文件放 `TEXTBOOK_ROOT/cases/standards`，通过教师侧鉴权接口读取；不写 `/profile/`，不生成假课次。
- 前端书架新增“高中”和“课程标准”两个分组；课标使用弹窗逐页预览和PDF下载，学生不显示。

## 后果

- 正面：教材和课标语义分离，课程绑定、目录和权限边界不被污染；课标可独立上下架、排序和扩展。
- 约束：课标需要独立预览缓存和下载权限；书架多一个资料分组，搜索和窄屏需要容纳长标题。
- 数据：正式库16册1840页、2份课标；原13册1301页、327课例/1050资源不变。

## 验证与回退

正式API覆盖教师书架16册、高中3册目录/页图、整册PDF、两份课标预览/下载、学生/匿名拒绝和既有课例未中断；真实教师1440/390/320浏览器热修后连续两次复跑通过。首次运行的空值脚本异常已定位为平台总览页卸载后的图表初始化竞态，修复在总览页丢弃迟到结果并检查空图表容器，独立前端release已上线。

回退：只撤销总览页热修时将Nginx根切回`20261109_high_school_textbooks_v1/frontend`并reload，不重启后端；回退整轮功能再恢复`service.before`/`nginx.before`并退回上一release。业务停用可只把高中教材和课标`status`置1、更新165转DRAFT。新增表、文件均为增量，保留不删，不整库回灌。
