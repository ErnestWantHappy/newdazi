# ADR-018：教研活动课例以来源帖子幂等，活动标题独立快照，压缩包必须深度检查

日期：2026-11-09。状态：已决定，白天准备完成，正式迁移待低峰窗口。

## 背景

教研活动中多名教师可能提交同名课程，且同一课例同时存在私有附件、云盘根目录文件、嵌套压缩包和需本地运行的工具。旧优秀课例`origin`是固定枚举，评价只对LEGACY开放；平台正在使用，白天不能重启或发布。

## 备选方案

1. 按课程标题+教师姓名upsert，直接把云盘链接当资源；实现快，但会覆盖同名旧课例，链接失效后留下空壳，无法保证文件真实。
2. 整批资源整体替换课例表；可控但破坏旧`case_id`、评价与资源引用，回退成本高。
3. 以`post_id`为稳定来源、活动标题独立快照，先深度检查并暂存文件，再在低峰窗口幂等DRAFT导入；复杂度较高，但可追溯、可回退、可重复执行。

## 决策

采用方案3。

- `source_key='research-post-<post_id>'`，`research_post_id`唯一；课程标题/教师不是幂等键，同名旧课例和资源完全保留。
- `research_topic_title`保存导入时完整活动标题，不写入`origin`；`origin='RESEARCH_ACTIVITY'`仅驱动「教研活动课例」标签，不改变LEGACY评价语义。
- 私有附件与教育云盘文件必须实际下载、按魔数识别、计算SHA-256、去重；压缩包必须列目录、递归检查嵌套包、读取文档/媒体信息、检查密码/路径/异常压缩比/可执行程序/快捷方式/个人信息。未检查完成不得上架。
- 原包作为ARCHIVE保留并生成真实中文说明；有教学价值的文档拆为独立资源并生成PDF预览；来源程序、`.url`、运行库和缓存不单独上架。
- 白天只生成staging与manifest；低峰窗口确认、课堂空闲、源文件指纹、整库备份和服务器哈希复核全部通过后才写DRAFT，验收通过再PUBLISHED。

## 后果与验证

- 增加一个项目级Skill、三列幂等DDL、后端来源字段/音频MIME和前端展示/分类调整；不换技术栈、不改权限模型、不重建课例表。
- 2026-11-09本机验证：Skill单测15项、后端教材定向40项、前端43项与生产构建通过；stage下载26文件325MB、检查2个独立包、生成9预览与2说明；manifest为READY_FOR_APPLY，3课例（郑东旭《语音合成》、赵琪《返回成语现场》、顾意丽《返回成语现场》）/17资源，文件无缺失或哈希不符。
- 130正式写入、真实接口和浏览器验收未执行；回退优先按`source_key`（`research-post-15`、`research-post-60`、`research-post-70`）转DRAFT并恢复旧前后端，新增文件按清单精确清理，不整库回灌。
