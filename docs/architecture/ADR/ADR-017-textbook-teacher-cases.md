## 决定

沿用教材书架和阅读器，以教材册+课次关联多份独立教师课例，再关联资源。两张新增表由审核后的离线脚本维护，运行期教师只读。不增加独立一级资源菜单。

课例资源保存在TEXTBOOK_ROOT/cases，与程序release分离；原件、PDF预览件分别保存。教师角色专用接口负责数量汇总、详情、预览和下载，不在学生共用目录接口中返回资源。

## 影响

教材升级或课次标识变化时需核对关联。发布前必须执行两表DDL、复制资源并核对权限；回退前端/后端不需要删除表和资源。首期本机样板不代表正式授权发布，全量原包需核对署名、授权、敏感数据及环境要求。

当前状态、证据与待办见contexts/textbook-cases/tasks.md。大包下载方式、手机PDF兼容与全量治理仍待闭环。

## 补充（2026-11-03 预览与分发边界）

- 预览件超过100MiB时改为离线逐页重采样（1920px、质量85的JPEG页面PDF）再入库，运行期100MiB上限作为兜底保留：把重复嵌入高清截图的PDF直接交给PDFBox渲染会让内存与耗时不可控，而前端本来按页取图，重采样不改变观感。原件与E盘来源保持只读。
- 实验包与素材分级：可直接收录、净化后收录、不收录。净化只移除配置、课堂数据库、编辑器备份与依赖目录，不改程序代码；含真实密钥、真实学生姓名或课堂提交记录且无法安全净化的，一律不随课例分发，理由写入 `package-decisions.json`。
- 该分级是本机审核结论，正式环境发布前须按目标库与真实文件重新核对，不能因本机已通过而跳过。

## 补充（2026-11-03 网页工程分发）

- 学单、投票、展示墙、课堂服务等网页工程按目录整体打包，保留相对路径；包内附与平台描述同源的说明文件，避免下载后发现需要额外安装或配置。
- 原作者的运行环境（Windows venv）绑定作者电脑的 Python 安装路径，换机无法启动，因此不作为"即开即用"分发；改为在说明中写明 Python 版本与依赖安装步骤。同理，自签名证书导致 HTTPS 启动的包改为 HTTP，并在说明中写明。
- 用户2026-11-03明确此模块分发的是教师教学资源，原作者自愿共享模型Key应保留。下载前说明共享Key可能失效、可替换自己的；旧课堂收集地址与模型Key分别处理，不以共享Key本身阻止上线。
- 超过 100MiB 的视频不做在线解码，界面提示下载后本地播放；这是对浏览器解码稳定性的取舍，不改变原件与下载。
