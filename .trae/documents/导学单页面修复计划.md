# 导学单页面修复计划

## 一、总结

通过分析发现两个问题：

1. **页面空白（数据不刷新）**：RuoYi-Vue3 的多标签页视图使用 `<keep-alive>` 缓存组件，第二次切换到该标签时 `setup` 不重新执行，`getList()` 不运行，导致页面空白。
2. **SurveyJS 设计器未加载**：`survey-core`、`survey-creator-knockout`、`survey-knockout-ui` 三个包在 `package.json` 中有声明但未安装到 `node_modules`，代码依赖全局 `window.SurveyCreator` 但未正确导入。

---

## 二、修复步骤

### 步骤 1：修复列表页 getList() 调用时机

**文件**: [index.vue](file:///E:/Project/newdazi/RuoYi-Vue3/src/views/business/guideSheet/index.vue)

**问题**: `getList()` 在 `<script setup>` 顶层调用（第 145 行），setup 只在组件首次创建时执行一次。RuoYi-Vue3 的 AppMain 使用 `<keep-alive :include="tagsViewStore.cachedViews">`，切换到其他标签再回来时不触发 setup，导致数据不刷新。

**修复方案**:
- 导入 `onMounted`、`onActivated` 生命周期钩子
- 将 `getList()` 移到 `onMounted` 中（确保 DOM 就绪后执行）
- 添加 `onActivated` 钩子，当标签页重新激活时重新调用 `getList()`
- 在 catch 块中添加 `ElMessage.error` 错误提示

**代码变更**:
```javascript
// 修改前
import { ref, reactive } from 'vue'
// ...
getList()

// 修改后
import { ref, reactive, onMounted, onActivated } from 'vue'
// ...
onMounted(() => {
  getList()
})
onActivated(() => {
  if (queryParams.pageNum === 1) {
    getList()
  }
})
```

### 步骤 3：添加 SurveyJS 全局导入

**文件**: [main.js](file:///E:/Project/newdazi/RuoYi-Vue3/src/main.js)

**问题**: `designer.vue` 和 `preview.vue` 依赖 `window.SurveyCreator` 和 `window.Survey` 全局对象，但项目中没有任何地方导入 SurveyJS 模块，这些全局对象不存在，导致 fallback 机制触发显示提示信息。

**修复方案**: 在 `main.js` 中导入 SurveyJS 核心库和样式，使其注册为全局变量。

**代码变更**:
```javascript
// 在 main.js 中添加
import 'survey-core/survey-core.css'
import 'survey-core/survey.i18n.js'
import 'survey-knockout-ui'
import 'survey-creator-knockout'
import 'survey-creator-knockout/survey-creator.css'
```
