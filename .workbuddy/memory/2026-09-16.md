### 制品一致性比对方法（可复用）

Spring Boot fat jar 的类在**嵌套 jar** 里，必须打开 `BOOT-INF/lib/ruoyi-business-3.9.0.jar` 再逐 `.class` 比。裸字节比对会被编译元数据污染（`MethodParameters`、`LocalVariableTable`、泛型签名），所以：
1. 先比"新增/删除/字节变化"清单，**REMOVED 必须为 0**；
2. 再对关键类解析**常量池 UTF8 集合**做语义比对；
3. 最后做**业务字符串硬校验**（如 `小组不属于当前学生班级`），证明功能确实在制品里。
本轮结论：她的编译用 `javac -parameters`、maven 不带 → 只差 `MethodParameters`；新制品多出的是调试表。`BizLessonServiceImpl` 同样只差调试表（线上那份缺 `LocalVariableTable`，新版本是严格超集），非语义变更。

### 环境坑（补充）

- PowerShell 工具的 stdout 常常不回显 → 一律"输出写文件再 Read"。
- PowerShell 里 `python ... *> file` 写出的是 UTF-16，Read 会当二进制 → 用 `| ForEach-Object { "$_" } | Out-File -Encoding utf8`，并加 `$env:PYTHONIOENCODING="utf-8"`。
- shell 脚本体**禁止用 Python `%` 格式化或 `.format()`**：`date '+%F %T'` 会撞 `%`，`%{http_code}` 会撞 `{}`。统一用 `__占位符__` + `.replace()`。
- `secrets.local.md` 里 EMQX 的 `API Key`/`API Secret` **没有反引号包裹**，按格式特征（16 位十六进制 / 40+ 位字母数字）识别最稳。
- EMQX 用户规则 PUT **必须带 `-u KEY:SECRET`**（漏了会 401，而不是 403，容易误判成权限不足）。
- surefire fork 崩溃是环境问题，AGENTS 里 `-Dtest` 还需 `-Dsurefire.failIfNoSpecifiedTests=false`（注意是 `surefire.` 前缀，不是 `failIfNoSpecifiedTests`）。
