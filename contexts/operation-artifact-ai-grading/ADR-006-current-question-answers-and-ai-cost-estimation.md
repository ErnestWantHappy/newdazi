# ADR-006：当前题目答案边界与 AI 理论费用估算

> 状态：已接受（2026-08-25）

## 背景

课程编辑会删除并重建 `biz_lesson_question`。旧实现仅删除题目关联，历史 `biz_student_answer` 仍留在在线表；部分批改与统计查询只按 `lesson_id` 取答案，因此已从课程移除的题目仍可能让班级显示“已提交/已批改”。同时，AI 结果已经保存 token，但教师无法看到用量或费用，模型价格也没有统一、可审计的维护位置。

## 备选方案

1. 只修课程 657 的脏数据。改动最小，但未来再次删题仍会复发，且其它统计口径继续分裂。
2. 统计统一连接当前题目，删题答案直接物理删除。能消除幽灵状态，但丢失学生作答与评分审计，不接受。
3. 统计统一连接当前题目，课程保存先归档再清理在线答案；价格入库并在任务创建时冻结，用已记录 token 计算理论费用。

## 决策

采用方案 3。

1. `biz_lesson_question(lesson_id, question_id)` 是课程答案进入在线统计的唯一资格边界。
2. 删除题目关系前，在课程保存事务内把答案复制到既有孤儿归档表，写批次元数据并逐步核对数量；失败时回滚整个课程保存。
3. 使用定向、幂等 SQL 处理已经存在的课程 279 旧题答案，执行前必须对目标库完整备份并前检。
4. 新建 `biz_ai_model_price`；管理员维护价格，教师只读。模型映射未确认时使用 `TO_CONFIRM` 状态和说明，而不是伪装成官方确定价格。
5. 新任务把价格复制到任务行，费用由结果表 token 汇总计算。旧任务无快照时引用当前价，但接口必须披露该口径。
6. 页面只展示理论估算并固定提示以阿里云实际账单为准；本轮不调用余额 API。

## 后果

- 删题后班级状态、成绩和学情不会再被旧答案污染，且审计证据仍可追溯。
- 课程保存多一次归档核对，迁移未执行或归档表异常时会安全失败；这是保护数据的预期行为。
- 新任务费用口径稳定，不受管理员后来改价影响；历史任务估算可能随当前价变化，页面会明确说明。
- 价格表引入管理员维护责任，默认价格在确认前只能用于参考。

## 验证证据

- `StudentAnswerArchiveServiceTest` 3/3；AI 价格与错误映射等专项合计 16/16；业务全量 371/371。
- admin clean package 和 Vue3 生产构建通过；两份 SQL 在本机连续执行两次成功。
- 浏览器临时插入一条不属于课程当前题目关系的已评分答案，班级已交人数仍为 40；测试行随后清理为 0。
- 教师读取价格成功，修改价格返回业务码 403；设置弹窗和任务详情抽屉的费用/免责声明可见。

## 回滚影响

应用可切回旧版本并保留新增价格表、归档表和任务可空列。若需要数据级回滚，优先恢复发布前整库备份；只有在同时恢复旧课程题目关系时，才可按归档批次把答案迁回在线表，否则会重新制造幽灵状态。
