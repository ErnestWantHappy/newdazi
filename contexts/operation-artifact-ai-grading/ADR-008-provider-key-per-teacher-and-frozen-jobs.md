# ADR-008：教师多厂商 Key 独立保存与任务快照续跑

日期：2026-09-23。状态：本地实现，未发布。

## 背景

旧配置表按教师只存当前百炼模型和一份 Key。切换厂商若覆盖该行，已有任务重试会读错 Key；教师也无法无损切回原厂商。

## 决定

增量表以教师＋厂商为主键存加密 Key、掩码和该厂商最后模型，旧配置表仅表示当前选择。操作题任务和学情诊断输入始终按创建时厂商/模型/价格取配置并续跑；旧学情输入缺厂商时沿用 QWEN。删除 Key 明确失败，不跨厂商降级。端点和视觉模型固定白名单，配置响应绝不返回密文。只接入已核对图片输入与 JSON 输出能力的首批三家，不提供任意兼容 URL。未知价格显示待确认，不按免费估算；学情诊断有费用软上限，单价未知时拒绝创建并提示维护价格。

## 迁移与验证

先备份并执行 `sql/operation_ai_multi_provider_keys_v1.sql`，保持原 `PRACTICAL_AI_MASTER_KEY`，再配套更新应用。`INSERT IGNORE` 迁入旧当前 Key，重复执行不覆盖新表已有值。应用回退保留新表和既有任务。本地隔离库完成三家 Key 切换/删除及安全响应测试，Java 图片请求契约通过；真实三厂商调用因缺 Key 待验。
