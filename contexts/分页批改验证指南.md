# 分页批改方案 — 快速启动指南

> 后端重启后生效

## 1. 启动后端

在项目的 Windows 终端中执行：

```cmd
cd E:\Project\newdazi\RuoYi-Vue
java -jar ruoyi-admin\target\ruoyi-admin.jar
```

等待约 30 秒直到 Spring Boot 初始化完成。

## 2. 一键验证脚本

替换 `<TOKEN>` 为实际 token，然后依次执行：

### 2.1 提交第一页（tabIndex=0）

```bash
curl -s -X POST http://localhost:8080/business/guide-sheet/student/submit \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"sheetId":24,"answerJson":"{\"radio94730\":1,\"textarea42476\":\"test\"}","currentPage":1,"action":"submit","tabIndex":0}'
```

**预期**：返回 `{"msg":"提交成功"}`

### 2.2 检查评分结果

```bash
curl -s "http://localhost:8080/business/guide-sheet/student/grading/24" -H "Authorization: Bearer <TOKEN>"
```

**预期**：`gradingDetail` 只包含 tabIndex=0 的 4 道题，totalScore=30（radio 得分），**不包含 checkbox**

### 2.3 切换到第二页提交（tabIndex=1）

```bash
curl -s -X POST http://localhost:8080/business/guide-sheet/student/submit \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"sheetId":24,"answerJson":"{\"checkbox49691\":[2]}","currentPage":2,"action":"submit","tabIndex":1}'
```

**预期**：`gradingDetail` 只包含 tabIndex=1 的 checkbox，totalScore ≈ 5

## 3. 前端验证

浏览器 `http://localhost:8083` → 学生登录 `2025780101` / `123456` → 导学单页面：

- 切换到"第一"标签页 → 点击提交 → 评分卡片显示 4 道题（radio、textarea、物联网技术分为几种、物联网架构分别有哪几层）
- 切换到"第二"标签页 → 评分卡片空白（该页未提交过）
- 在"第二"标签页点击提交 → 评分卡片显示 1 道题（checkbox）

## 4. 获取 Token 的快捷命令

```bash
curl -s -X POST http://localhost:8080/login \
  -H "Content-Type: application/json" \
  -d '{"username":"2025780101","password":"123456"}' \
  | grep -o '"token":"[^"]*"' | cut -d'"' -f4
```
