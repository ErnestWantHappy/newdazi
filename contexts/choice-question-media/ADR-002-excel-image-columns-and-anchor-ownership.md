# ADR-002：Excel 图片专用列与锚点归属

2026-11-09，本机实现，尚未发布。

## 背景

Excel/WPS 单元格内插入图片会替换单元格已有文字，题干和选项无法在同一格同时稳定保存文字与图片。旧模板依赖“浮动图片覆盖同一文字格”的识别方式，遇到图片缩放、跨行或客户端格式差异时容易把图片归到错误题目。

## 决策

1. 原文字列保持原顺序和语义不变：题目类型、题目内容、年级、学期、第几课、选项A-D、标准答案、题目解析、是否公开、创建人。
2. 新模板在右侧增加 7 个图片专用列：题干图片1-3、选项A图片、选项B图片、选项C图片、选项D图片。文字只写原列，图片只放对应图片列。
3. 图片专用列按图片左上角锚点所在的列决定槽位，不按图片覆盖面积或中心点猜列；同一槽位仍检查垂直方向是否跨到下一题行。若跨行明显，图片进入“待确认图片”，由教师在预览中选择题目/位置。
4. 旧模板继续兼容：没有图片专用列时，仍按原文字格 + 浮动图识别；该路径保留“主要覆盖面积达到 85%”规则，覆盖不足或跨语义格时要求确认。
5. 导出使用相同图片专用列，使“导出→再导入”不把图片塞回文字格，也不丢失图文关系。
6. 保持 POI 4.1.2 和专用 `QuestionWorkbookReader/Writer`，不升级全局 `ExcelUtil`。WPS `DISPIMG/cellimages.xml` 做受限解析；Excel 365 `richData` 只检测并提示改用浮动图片或预览粘贴截图，不宣称全自动兼容。

## 影响

- 不需要数据库迁移，导入批次、预览、原子确认和图片鉴权链路不变。
- 旧模板仍可用；新模板减少“文字被图片顶掉”和“图片落错列”的风险。
- 真实 WPS/Excel 多版本、裁剪/旋转、跨行或合并格仍需样本验收；无法可靠判断时不自动猜，保留在线修正入口。

## 未采用方案

- **继续只在原文字格放浮动图**：仍受文字被覆盖、面积归属和客户端渲染差异影响，不能解决“同格文字+图片”的根本问题。
- **让教师填写图片 ID、路径或图片引用列**：把技术细节转嫁给教师，且导出回导和错误修正更复杂，不采用。
