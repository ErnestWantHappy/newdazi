# ADR-001：增量媒体与安全另存

2026-11-06，用户确认。

保留原文字结构、A—D评分，以media_json与受控图片元数据扩展选择题。已使用含图题内容修改后台另存，返回最终ID并定位；不自动改已发布课程、历史答案和成绩。普通旧纯文字题编辑规则不扩大修改。

导入接收原Excel中的真实图片，采用专用POI图文reader/writer及持久化预览和原子确认，不使用图片ID模板。现有POI版本不默认升级；不支持的图片格式明确检测并允许在线截图替换，不承诺所有WPS/Excel存储变体自动解析。

暂不引入B的统一内容版本表/普通课全量快照，未来确需版本树/逐课升级再演进；不能以“自动另存”宣称已有完整版本系统。

本机实现与验证完成后，已随130正式1.30.82上线。生产原文件放release外独立私有目录`/data/upload-question-images`，而非公开上传子目录，避免静态资源绕过业务授权；仅TEMP可七天回收，历史RETAINED永久保留。实际Excel/WPS新式图片格式、整班并发、区域抽测图片页及磁盘长期增长仍待验收，不能以生成样本测试宣称兼容所有客户端。[正式验收](release-1.30.82.md)

2026-11-09 本机追加 Excel 图片专用列 v3，旧模板兼容；该决策不改变本ADR的媒体增量、权限与安全另存边界，具体见[ADR-002](ADR-002-excel-image-columns-and-anchor-ownership.md)。
