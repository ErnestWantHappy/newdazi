# 选择题图片支持需求

2026-11-06 用户确认增强A及五页UI；2026-11-09 已随130正式1.30.82发布并完成正式API、浏览器和数据清理验收。同日追加本机v3图片专用列，未发布。

- 旧纯文字题与A—D单选评分保持。题干最多3图，每选项1图，可纯图片或图文；不要求图片地址/ID/图注。
- 教师点击、粘贴、拖拽自动上传，预览/更换/删除，保存反馈与刷新恢复可靠。
- 被课程/历史引用的含图题或拟加图题，实质内容修改自动另存，原课程不换题/不迁分，返回新题并可找回；保存幂等。
- Excel 支持 50 题一批，先预览在线修正再确认。v3 新模板把图片放到题干图片1-3、选项A-D图片专用列，文字留在原列；旧原模板继续兼容。图片专用列按左上角锚点所在列归属，跨题行或归属歧义不能静默猜。
- 专用POI解析，不全局改ExcelUtil；优先现有POI4.1.2和普通浮动位图，现代in-cell格式需明确检测与补救。
- 整批原子提交/防重复/结果恢复，持久化预览；图文导出回导。
- 题库、普通课组卷/学生/错题/教师学情、抽测组卷/个人快照完整透传；图片归属鉴权与原图保留。
- 详细边界以 `docs/choice-question-images-implementation-plan-20261106.md` v2和Excel专项为准。
