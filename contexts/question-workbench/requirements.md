# 题库工作台：需求（2026-11-05，本机）

教师进入题库后默认看到紧凑的题目缩略总览，直接浏览、查找、新增、编辑、删除题目，而不是先面对一张大表格。

## 用户与任务

- 角色：教师（兼有教研员身份时同样适用）、管理员。服务端权限与归属是最终边界。
- 核心任务：按题型找题 → 看摘要 → 进详情/预览 → 新增对应题型 → 保存后能再找到。
- 次要任务：搜索与筛选、加载更多、查看全部并批量管理、常规题与 Python 题导入、非操作题导出。

## 明确不做

- 不新增后端接口或数据库迁移；操作方式题量用现有分页接口的 `total` 按范围查询，FILE 历史空值兼容由 Mapper 实现。
- 不改变 DATA_LAB 专用编辑器的数据契约，不为统一外观添加年级/学期字段。
- 不把示例题、示例数量或设计图中的按钮组合写进产品。
- 不新增一级菜单、路由或视图切换器；查看全部在原页面内切换。
- 不发布、不推送、不改正式数据。
