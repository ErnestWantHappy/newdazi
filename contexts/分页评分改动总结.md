# 分页评分改动总结

## 需求

提交导学单时，只批改当前标签页的内容，不批改其他页的题。

## 改动概览

| 文件 | 改动说明 |
|------|---------|
| `GuideSheetGradingService.java` | GradingResult 新增 pageScore/pageMaxScore/pageGradingDetail；grade() 委托给 gradePage(..., null)；新增 gradePage(..., targetTabIndex) 方法 |
| `IGuideSheetAnswerService.java` | 新增 submitAnswer(BizGuideSheetAnswer answer, Integer tabIndex) |
| `GuideSheetAnswerServiceImpl.java` | submitAnswer(answer) 委托给 submitAnswer(answer, null)；submitAnswer(answer, tabIndex) 实现分页评分 |
| `GuideSheetController.java` | 从 request body 解析 tabIndex 参数 |
| `student/guideSheet/index.vue` | handleSubmit() 提交时传 tabIndex |

## 核心逻辑

```
学生提交（tabIndex=0）
  → 前端 POST {tabIndex: 0}
    → Controller 解析 tabIndex=0
      → Service.submitAnswer(answer, 0)
        → gradePage(formJson, answerJson, studentId, sheetId, 0)
          → 遍历所有字段，仅处理 tabIndex=0 的
          → 返回 pageGradingDetail=[{tabIndex:0 的4道题}]
        → answer.gradingDetail = pageGradingDetail
        → DB 写入 grading_detail
  ← GET /grading → gradingDetail 仅含第一页的题
  ← 前端 filteredGradingDetails 显示当前页评分
```

## 验证方式

详见 `分页批改验证指南.md`：
1. 提交当前标签页 → 评分只显示当前页的题
2. 切换到未提交的标签页 → 评分卡片为空
3. 在第二个标签页提交 → 评分显示第二个标签页的题

**前提**：后端需要重启才能加载新代码。
