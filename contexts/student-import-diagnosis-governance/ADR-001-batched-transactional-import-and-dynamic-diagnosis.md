# ADR-001：采用事务批量导入与动态诊断分级

- 状态：已接受，1.27.8 已正式发布
- 日期：2026-09-01

## 决策

学生导入保留同步接口和现有 Excel 模板，采用“同校 Redis 锁 + 全量预校验 + 单次 BCrypt + 200 条批量写入 + 单事务回滚 + 联合查重索引”。监控不修改历史事件表结构，在持久化新事件和读取历史事件时共用同一诊断规则动态分类。

## 理由

- 正式证据显示主要耗时来自逐行 BCrypt 和逐行数据库往返，没有引入异步任务系统的必要。
- 同步结构化响应对教师最直观，也能保留当前页面和权限模型。
- 普通 `(user_name, del_flag)` 索引兼容现有软删除同名账号语义；分布式锁和事务数量核对负责本轮并发收敛。
- 动态重算可立即修正历史误报展示，不需要批量改日志或增加字段。

## 后果

- Redis 不可用时导入会明确失败，避免失去防重后继续写库。
- 同批学生共用一个初始密码哈希；这与平台当前统一初始密码规则一致，显著减少 CPU 消耗，后续仍按现有流程修改密码。
- 正式发布新增一个普通索引，必须备份、前检、执行、后检；应用和索引可独立回滚。
