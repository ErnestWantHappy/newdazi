# 三份 AI 审查报告复核与修复

日期：2026-10-07。依据：当前源码、专题约束、定向测试。工作区原有大量未提交改动，本轮保留；不以 Git 总 diff 冒充本轮改动。未运行 AOCI 全量工作流，未同步索引。

## 报告质量判断

仅评价这次审查：DeepSeek 的具体缺陷覆盖最完整；Qwen 找到了额外的布局保存、跨标签登录、设备重复注册问题，但混入了既定统计口径和性能改进项；Gemini 对部分安全保护的说明成立，却把尚未 aligned 的索引当成最高依据，并用“有错误处理代码”推断“兜底有效”，漏掉了实际可复现问题。因此本轮报告质量排序为 DeepSeek、Qwen、Gemini，不代表模型所有任务的能力排名。

## 用户本轮确认的规则

- 保留登录页真实教研图片公开展示，只统一校验主题、学校和作者有效性。不会因为旧 ADR 的“仅摘要”限制撤掉当前图片，也不强制要求另开分享链接。
- 保持独立课堂表现计分规则，包含 0 分。课堂表现记录不能与空文件占位混为一谈。
- 课堂任务汇总与成绩人数是不同事实；现行任务优先级及 30 秒轮询不因报告建议而改成新业务规则。

## DeepSeek 逐条核对

| 编号 | 结论 | 处理与边界 |
| --- | --- | --- |
| D1 外链图片代理必然失败 | 成立 | 提取时跳过不受支持的外链，不发起服务端外网抓取；本地资源包装路径仍由原解析器复核。 |
| D2 轮播失败兜底不响应 | 成立 | 用响应式失败地址集合驱动 computed，浏览器单张 404 已验证恢复本地图。 |
| D3 匿名跟帖图不检查父主题 | 部分成立 | 删除父主题、停用学校/作者的可读性漏洞成立；公开有效图片及图片 ID 本身是当前确认需求，不能全部称越权。列表与图片接口均校验父主题及双方学校/作者。 |
| D4 刷新绕过选校 | 成立 | 保存待选校标记，守卫保留登录页，刷新重新取校区并显示选择框；标记不承担服务端授权。 |
| D5 关闭操作题阻止退回文件重交 | 成立，且前端也有漏项 | 上传/提交按当前课 RETURNED 豁免，前端关闭开关时仍展示退回题；旧课仍拒绝。 |
| D6 删除空作品仍计推进人数 | 成立，且班级选择人数也受影响 | 两处人数采用成绩汇总的实际答案/成绩/版本事实；保留理论、打字和独立课堂表现规则，不清历史分。 |
| D7 区域抽测接受无法页图化文件 | 上传与转换不匹配成立 | 上传收敛为现有转换器支持的 Office/PDF/JPG/JPEG/PNG；7Z 不应扩展到区域抽测。已有不受支持的历史文件未迁移。 |
| D8 校级成绩下载 7Z 失败 | 成立 | 下载白名单补 7Z，通用上传白名单未扩展；原资源授权与路径校验保留。 |
| D9 HTML DOCTYPE 被前插 meta 破坏 | 成立 | 文档声明及前导注释放在策略之前，策略仍先于用户元素/脚本；浏览器验证 CSS1Compat。 |
| D10 流程图重载显示旧提交 | 成立 | 面板 key 包含提交 ID，读取指定 versionNo，避免名单基线与最新图异步漂移。 |
| D11 草稿冲突无恢复入口 | 成立 | 增加使用平台/保留本机选择，重新读取修订号再保存；冲突时禁止继续编辑，已批改切正式版只读且保留本地备份。 |
| D12 确认 0 人显示 N 人 | 成立 | 使用空值回退，0 原样显示，失败刷新实际机位。 |
| D13 状态失败显示未关联 | 成立 | 保留上次关联，明确“状态待核对”；首次失败也能看到原因。 |
| D14 班级/统计失败显示无数据 | 成立 | 失败显示不可用，不再标记统计已加载。 |
| D15 切班残留轮询 | 成立 | 定时器在同步 watcher 中建立，旧异步回调不能再创建定时器；首次失败继续重试，卸载清理。 |
| D16 未显示反馈发布时间 | 展示遗漏，非数据泄漏 | 展示已有 publishedAt，不改反馈快照。 |

## Qwen 逐条核对

| 编号 | 结论 | 处理与边界 |
| --- | --- | --- |
| Q1 跨标签退出后登录残留 | 成立 | 点击登录前与 Cookie 同步，清旧角色/权限；浏览器模拟残留后确认重新发送登录请求。 |
| Q2 所有匿名图均为越权 | 部分成立 | 父主题等有效性缺失已修；“不开放分享就不能展示任何图”与本轮确认的公开需求不符。 |
| Q3 外链破图和兜底 | 成立 | 同 D1/D2。 |
| Q4 错误重复弹窗 | 成立 | 请求层标记已通知错误，登录页不重复弹；本地构造/页面错误仍可提示。 |
| Q5 保存布局清空课堂状态 | 成立 | 合并布局响应与原概览，保留任务、表现、理论/操作成绩。 |
| Q6 已进入优先于部分已提交 | 既定规则，不算 Bug | 任务进度不等于“至少有一个成绩”；保持架构规定优先级。 |
| Q7 课堂表现计入成绩分母 | 用户确认保留，不算 Bug | 不修改评分与导出规则。 |
| Q8 大屏 30 秒轮询不是 WebSocket | 改进项，不算已证实故障 | 没有即时更新的已确认验收要求；不新增订阅架构。 |
| Q9 首次机位请求失败永久消失 | 成立 | 保留重试轮询和可见手动重试入口。 |
| Q10 改机房丢失基准 | 部分成立 | 设备改归属不等于整间机房改名，不能自动搬移所有基准；修复旧机房在选择项消失的问题，仍可查看原基准。 |
| Q11 一人变化整批确认失败 | 服务端保护正确，恢复体验不足 | 保持提交前整批核验，失败后刷新最新名单，不将旧观测静默写入基准。 |
| Q12 自动关联后注册码重复设备 | 成立 | 学校锁内查指纹，已有有效设备拒绝重复注册，提示从管理入口改名；历史重复设备未批量治理。 |
| Q13 编辑时被批改原因丢失 | 成立 | 展示实际服务端原因，恢复入口重新核验后进入正式版只读。 |

## 本轮独立发现

1. 机位确认对话框期间可重复点击，且切班后旧名单可能配上新 scope：确认前即锁按钮，确认后复核课班机房。
2. 文件重交除后端开关校验外，前端 practicalQuestions 也将所有关闭题过滤；已同时修复。
3. 空作品除了自动推进人数，还污染 selectClassStatusByLesson 的 scoreReadyCount；已同时修复。
4. 流程图刷新除重建组件外，仍需按名单版本读取，不能无条件读取最新提交；已传 versionNo。
5. 单主题匿名图同样缺少学校/作者有效性校验；已与活动列表统一。
