**新增私有方法**（添加到 Controller 类中）：
```java
/**
 * 过滤 formJson 中的敏感字段，防止泄露给学生端。
 * 移除：_scoringConfig（参考答案快照）、_aiApiKey、_aiProvider、_aiModel、_aiCustomUrl
 * 同时移除 widgetList 中各 widget 的 scoring 属性
 */
@SuppressWarnings("unchecked")
private String sanitizeFormJsonForStudent(String formJson) {
    if (formJson == null || formJson.isEmpty()) {
        return formJson;
    }
    try {
        ObjectMapper mapper = new ObjectMapper();
        Map<String, Object> jsonMap = mapper.readValue(formJson, Map.class);
        
        // 移除顶层敏感字段
        jsonMap.remove("_scoringConfig");
        jsonMap.remove("_aiApiKey");
        jsonMap.remove("_aiProvider");
        jsonMap.remove("_aiModel");
        jsonMap.remove("_aiCustomUrl");
        
        // 递归移除 widgetList 中各 widget 的 scoring 属性（也包含答案）
        List<Map<String, Object>> widgetList = (List<Map<String, Object>>) jsonMap.get("widgetList");
        if (widgetList != null) {
            removeScoringFromWidgets(widgetList, new HashSet<>());
        }
        
        return mapper.writeValueAsString(jsonMap);
    } catch (Exception e) {
        log.warn("过滤 formJson 敏感字段失败，返回空表单", e);
        return "{}";
    }
}

/**
 * 递归移除 widget 树中的 scoring 属性（防止通过 widget.options.scoring 泄露答案）
 */
@SuppressWarnings("unchecked")
private void removeScoringFromWidgets(Object value, Set<Object> visited) {
    if (value == null || visited.contains(value)) return;
    if (value instanceof List) {
        for (Object item : (List<?>) value) {
            removeScoringFromWidgets(item, visited);
        }
    } else if (value instanceof Map) {
        Map<String, Object> map = (Map<String, Object>) value;
        visited.add(map);
        // 移除 scoring 属性（widget 顶层和 options 内）
        map.remove("scoring");
        if (map.get("options") instanceof Map) {
            ((Map<String, Object>) map.get("options")).remove("scoring");
        }
        // 递归处理所有子属性
        for (Object v : map.values()) {
            if (v instanceof Map || v instanceof List) {
                removeScoringFromWidgets(v, visited);
            }
        }
    }
}
```

> **关键点**：需要使用 `com.fasterxml.jackson.databind.ObjectMapper`（Controller 已有相关 import）。这个方法同时清理了顶层敏感字段（`_scoringConfig` 等）和 widget 树中的 `scoring` 属性（VForm3 保存在 `widget.options.scoring` 中）。

## 二、P1 高优先级修复方案

### BUG-04：checkbox 多选"部分给分"计算逻辑错误

**影响文件**：
- `RuoYi-Vue/ruoyi-business/src/main/java/com/ruoyi/business/service/GuideSheetGradingService.java`

**问题根因**：评分流程如下：
1. `_scoringConfig` 快照中的 `answer` 如果是数组 → `snapshotAnswerToString` 方法调用了 `normalize(answer)` → List 被 join 为 `"2,3"` 字符串
2. 传入 `gradePartialCheckbox(correctStr)` 后，`correctStr` 是 `"2,3"` 字符串
3. 走到 `else` 分支：`correctList.add(normalize(correctAnswer))` → 得到 `["2,3"]` 仅一个元素
4. 学生选了 `["2"]`，`correctList.contains("2")` 返回 `false` → 学生得 0 分

**修复方案**：

修改 `gradePartialCheckbox` 方法（第466-496行），在解析正确答案时处理逗号分隔的字符串：

修改后：
```java
@SuppressWarnings("unchecked")
private int gradePartialCheckbox(Object studentAnswer, Object correctAnswer, int maxScore) {
    List<String> studentList = new ArrayList<>();
    List<String> correctList = new ArrayList<>();

    // 解析学生答案
    if (studentAnswer instanceof List) {
        for (Object item : (List<?>) studentAnswer) {
            studentList.add(String.valueOf(item).trim());
        }
    } else {
        studentList.add(normalize(studentAnswer));
    }

    // 解析正确答案 —— 修复：处理逗号分隔的字符串
    if (correctAnswer instanceof List) {
        for (Object item : (List<?>) correctAnswer) {
            correctList.add(String.valueOf(item).trim());
        }
    } else {
        // === 修复开始 ===
        String normalized = normalize(correctAnswer);
        if (normalized.contains(",")) {
            // 逗号分隔字符串：拆分为多个选项
            for (String part : normalized.split(",")) {
                String trimmed = part.trim();
                if (!trimmed.isEmpty()) {
                    correctList.add(trimmed);
                }
            }
        } else if (!normalized.isEmpty()) {
            correctList.add(normalized);
        }
        // === 修复结束 ===
    }

    if (correctList.isEmpty() || studentList.isEmpty()) {
        return 0;
    }

    // 计算答对的选项数
    long correctCount = studentList.stream().filter(correctList::contains).count();
    // 按比例给分
    return (int) Math.round((double) correctCount / correctList.size() * maxScore);
}
```

> **修复原理**：在 `correctAnswer` 为字符串类型时，先按逗号拆分为多个独立选项，再逐个匹配。这样学生选对 1/3 → 得 33% 分数（即 BUG-04 描述的行为才能正确工作）。

@PutMapping("/progress/heartbeat")
public AjaxResult heartbeat(@RequestBody Map<String, Object> request)
{
    LoginUser loginUser = SecurityUtils.getLoginUser();
    if (loginUser == null)
    {
        return error("用户未登录");
    }
    BizStudent student = bizStudentMapper.selectBizStudentByUserId(loginUser.getUserId());

    return success("心跳上报成功");

```

@GetMapping("/export")
public void export(HttpServletResponse response,
                   @RequestParam("sheetId") Long sheetId,
                   @RequestParam(value = "classCode", required = false) String classCode)
{
    // 1. 查询答案列表
    List<BizGuideSheetAnswer> answerList;
    if (classCode != null && !classCode.isEmpty()) {
        answerList = guideSheetAnswerService.getBySheetIdByClassCode(sheetId, classCode);
    } else {
        answerList = guideSheetAnswerService.getBySheetId(sheetId);
    }

    // 2. 批量查询学生信息（修复 N+1 问题）
    List<Long> studentIds = answerList.stream()
            .map(BizGuideSheetAnswer::getStudentId)
            .distinct()
            .collect(Collectors.toList());
    Map<Long, BizStudent> studentMap = new HashMap<>();
    if (!studentIds.isEmpty()) {
        List<BizStudent> students = bizStudentMapper.selectBizStudentByStudentIds(studentIds);
        for (BizStudent s : students) {
            studentMap.put(s.getStudentId(), s);
        }
    }

    // 3. 获取导学单标题
    BizGuideSheet sheet = guideSheetService.getBySheetId(sheetId);
    String sheetName = sheet != null ? sheet.getSheetTitle() : "导学单答案";
    String exportName = sheetName + "_答案数据";

    // 4. 构建导出 VO
    List<GuideSheetExportVo> exportList = new ArrayList<>();
    for (BizGuideSheetAnswer answer : answerList) {
        BizStudent student = studentMap.get(answer.getStudentId());  // 从 Map 中获取
        GuideSheetExportVo vo = new GuideSheetExportVo();
        vo.setStudentName(student != null ? student.getStudentName() : "未知");
        vo.setStudentNo(student != null ? student.getStudentNo() : "");
        vo.setClassCode(student != null ? student.getClassCode() : "");
        vo.setStatus(convertStatus(answer.getStatus()));
        vo.setTotalScore(answer.getTotalScore() != null ? answer.getTotalScore() : 0);
        vo.setGradingStatus(answer.getGradingStatus() != null ? answer.getGradingStatus() : "pending");
        vo.setSubmitTime(answer.getSubmitTime());
        exportList.add(vo);
    }

    ExcelUtil<GuideSheetExportVo> util = new ExcelUtil<>(GuideSheetExportVo.class);
    util.exportExcel(response, exportList, exportName);
}
```

> **性能对比**：100个答案，修复前 101 次查询，修复后仅 2 次查询（答案查询 + 批量学生查询）。

### BUG-14（新发现）：评分去重失败

**影响文件**：
- `RuoYi-Vue/ruoyi-business/src/main/java/com/ruoyi/business/service/GuideSheetGradingService.java`

**问题根因**：`flattenWidgets` 方法通过 `walkFlatten` 递归遍历时，同一个 widget 被两个不同的引用路径发现（如通过 `widgetList` 数组引用一次，通过 `options` 的某个属性再引用一次）。`IdentityHashMap` 只防止同一对象引用被处理两次，但如果同一 widget 以不同方式被引用（例如在 `options` 中有嵌套的引用），会绕过防重检测。

**修复方案**：

在 `GradeSheetGradingService.java` 的 `grade` 方法中（第220-240行附近），在添加评分详情之前，先用 fieldKey 做去重检查：

修改方式：在 `flattenWidgets` 的 `walkFlatten` 方法中，改用 **按 id/name 去重**（而非仅按对象引用去重）：

修改 `walkFlatten` 方法（第341-366行）：

```java
@SuppressWarnings("unchecked")
private void walkFlatten(Object value, List<Map<String, Object>> result,
                         Set<Object> visited) {
    if (value == null || visited.contains(value)) return;
    visited.add(value);

    if (value instanceof List) {
        for (Object item : (List<?>) value) {
            walkFlatten(item, result, visited);
        }
    } else if (value instanceof Map) {
        Map<String, Object> map = (Map<String, Object>) value;
        Object id = map.get("id");
        if (id == null) id = map.get("name");
        Object type = map.get("type");
        if (id != null && type != null && isRealWidget(map)) {
            // === 修复：按 fieldKey 去重，避免同一 widget 被重复添加 ===
            String fieldKey = String.valueOf(id);
            boolean alreadyAdded = result.stream()
                    .anyMatch(w -> fieldKey.equals(
                            String.valueOf(w.getOrDefault("name", w.get("id")))));
            if (!alreadyAdded) {
                result.add(map);
            }
            // ================================================================
        }
        // 继续深入子属性
        for (Object v : map.values()) {
            if (v instanceof Map || v instanceof List) {
                walkFlatten(v, result, visited);
            }
        }
    }
}
```

> **性能注意**：`result.stream().anyMatch(...)` 在每个 widget 时扫描一次，时间复杂度 O(n²)。如果 widget 数量不多（通常 < 50），影响可忽略。如果 widget 很多，可用 `Set<String> seenKeys` 替代。
