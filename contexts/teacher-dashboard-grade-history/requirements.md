# 教师首页课程年级分栏与加载提速需求

> 状态：2026-08-09 已实现、提交并发布正式服务器；待用户明确要求后推送分支。

## 1. 产品目标

教师首页在稳定届别下按课程开设年级区分当前课程与历史课程；每个开设年级独立计算课次，并在不阻塞课程卡片展示的前提下补充批改红点和区域抽测信息。

## 2. 已确认需求

### REQ-01 两级分组

- 第一层按稳定届别分组，例如“2024级（当前九年级）”。
- 第二层按课程开设年级分栏。
- 当前年级分栏始终存在，即使课程数为 0；当前年级默认展开。
- 历史年级分栏按年级从近到远排列并默认折叠，点击一次展示该栏全部课程。
- 共享课程与自建课程使用相同分栏规则。

### REQ-02 历史课程管理

- 历史课程仍可设计、修改、删除、指派、批改和查看成绩。
- 历史分栏允许新增对应开设年级课程，但入口必须明确显示目标年级，避免误建。
- 课程创建后，届别和课程开设年级均不可直接修改；跨届或跨年级复用应复制为新课程。

### REQ-03 独立课次

- 课次唯一计算范围为同学校、同教师、同届别、同课程开设年级。
- 上下学期共用连续课次，不按学期重置。
- 当前年级没有课程时，新建课默认为第 1 课。
- 前端仅展示建议课次，服务端必须按相同范围兜底计算。

### REQ-04 推进边界

- 自动推进和手动推进只能在同学校、同教师、同届别、同课程开设年级内寻找下一门常规课。
- 当前年级的一键推进不得跳入历史年级课程。
- 历史课程仍可被教师显式指派和使用，但不能因课次相同或更大而与其他开设年级串联。

### REQ-05 首屏加载

- 年级与课程卡片先返回并渲染，不等待区域抽测入口或操作题批改状态。
- 区域抽测入口和批改红点分别异步补充；补充失败不清空已显示课程。
- 首次进入不得因 `mounted` 与 `activated` 生命周期重复请求首页数据。
- 页面从课程设计页返回时仍应刷新课程数据。

### REQ-06 历史数据治理

- 数据修改前必须备份并先生成修正清单。
- 仅自动修正证据明确且无歧义的数据：初中部郑东旭教师的2025级七年级课程 263～266 从 12～15 修正为 1～4，八年级课程267从16修正为1。
- 2024级八年级课程存在重复第1课和缺号，本轮不自动重排。
- SQL 必须限定学校、教师、届别、开设年级、课程ID和原课次，任一前置条件不符即中止。

### REQ-07 通用范围

- 代码规则适用于所有学校、教师、自建课程和共享课程。
- 数据修正 SQL 只处理上述已确认的明确记录，不扩展为全库自动重排。

## 3. 验收标准

- 2025级七年级与八年级课程分栏分离；执行修正 SQL 后课次分别为1～4和1。

- 首页课程核心请求不包含逐课程、逐班级批改期限计算；页面先显示课程，红点随后补齐。
