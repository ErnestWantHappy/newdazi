# ADR-004 学生直接运行机位助手

日期：2026-10-05；用户选择方案1，取代学生安装时填写管理员配置的流程。

学生从已登录平台下载 EXE 后直接运行。下载只在 PE 文件末尾携带公开平台根地址，不含学生账号、密码、登录令牌或注册码。客户端自动读取本机内网 IPv4 和机器指纹，发起五分钟短期配对，并打开原网页登录。学校归属仅取已登录学生所在学校，匿名请求不能指定学校。

浏览器单次消费配对链接，设备登记锁学校行。同校同指纹的有效设备复用原 ID、机房和机位，损坏本机配置后可自动恢复；被管理员撤销的设备不能自动恢复。数据库成功提交后才发布两分钟配对结果。只有持有客户端独立随机轮询凭据的一方能领取密钥，DPAPI 保存成功后确认领取。浏览器从不取得设备密钥。

新设备暂记“未分配机房”和机器标识。教师在当前授权课堂中设置机房、机位并显式确认常用机位；学生无此权限。原学校隔离、30秒心跳、75/90秒失效和历史课堂禁写规则保留。直接网页登录、未安装、助手故障和设备撤销都不阻断教学。

复用现有三表和 Redis，无结构迁移、新依赖或第二套账号。普通启动不调用管理员配置窗口；`--configure` 仅保留高级人工注册兼容入口。安装优先 D 盘，回退当前用户应用目录；桌面快捷方式和自启仍按当前 Windows 用户建立。Windows10、极域、还原卡与镜像克隆必须在真实机房现场验证，不由开发机测试代替。

本轮发布状态与证据以 [PROJECT_CORE](../../PROJECT_CORE.md) 最新记录为准。
