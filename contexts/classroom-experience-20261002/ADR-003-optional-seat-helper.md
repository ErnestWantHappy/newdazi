# ADR-003：可选机位助手与教师确认的长期基准

> 2026-10-03用户修订：没有HTTPS也要正式可用，助手为可选增强。1.30.26已启用全局及61校，HTTP/HTTPS均支持；原HTTPS前置取消。HTTP没有传输加密，应在学校可信网络使用；设备哈希、DPAPI和单次凭证不等于链路加密。未安装或故障不影响正常教学已正式验证。真实机房逐机安装仍待校方实施，证据见 [助手正式验收](seat-helper-release-verification-20261003.md)。

日期：2026-10-02。状态：用户已确认，本机试点链路已实现；机房现场未验。

浏览器看到的连接 IP 不能可靠识别 NAT 后的机房电脑。选用独立 Windows 轻量助手上报内网 IPv4，以服务器注册的设备密钥和机器指纹关联短时一次性浏览器凭证，原浏览器登录原平台，不建设第二套学生登录。服务全局和学校开关默认关闭，下载按钮仅向启用学校显示。

设备身份不以 IP、机器名或浏览器字段自报认定。注册由管理员创建的一次性注册码限定学校/机房/机位，学校配置行与设备当前读串行化注册，同一机位并发只允许一个有效设备。凭据服务端只存哈希，客户端 DPAPI 加密，硬件标识变化需撤销后重新配置。URL fragment 清理后才进入登录守卫，关联 token 不进入登录 redirect 查询参数。

常用机位按学校/机房/班级/学生长期保存，仅教师显式确认或单人调整可更新。观察位置改变、重复账号、缺席/离线/未识别不自动覆盖基准。换位链中被拒绝者的旧机位一并保留，避免产生重复绑定；当前课行锁防止推进后修改历史机位。机位与卡片拖动、协作分组、考勤分离。

方案提供管理提醒，不强制锁座或封禁，不保证真实操作者身份，也不能完全阻止人为转发 60 秒链接。私网 IP 仅辅助观察，IP 变化不等同于设备变化。助手故障不阻碍网页教学。

网页不能静默保存 D 盘、安装或启动程序。首次安装、自启项、快捷方式与 DPAPI 密钥必须由学校管理员纳入还原基线。实际 EXE、源码、编译/校验、安装/撤销/卸载说明见 `clients/seat-helper/`；Windows 10、极域批量分发、还原后自启、重装及镜像克隆待一间真实机房现场验收。

## 2026-10-03 审查修复补充

网页续期生命周期放在学生布局，首页组件只展示。管理请求按学校及代次校验，切校清注册码，撤销防重，退出清未消费凭证。注册返回学校公开platformUrl；客户端保存独立公开根地址供接口故障降级，并支持损坏配置/管理员重新配置。旧配置无可靠地址时需补填或成功打开建立缓存；普通网页服务全部不可达时不承诺可用。0.1.1-pilot与7项异常测试见 [修复验收](repair-verification-20261003.md)，机房还原基线须包含公开地址文件。

## 2026-10-07 本机修复补充

保持按机房显式确认的基准边界。设备跨机房不自动搬移基准，旧基准机房继续可选可查；注册码拒绝同校同指纹已有有效设备，提示使用管理命名。确认前观测变化仍整批拒绝，前端刷新恢复而不自动写入。请求失败不解释为设备未关联；唯一轮询可重试。见 [核验记录](../bug-review-20261007.md)。
