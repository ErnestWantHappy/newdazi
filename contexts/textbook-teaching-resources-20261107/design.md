## 复用与隔离

- 复用 Vue3 书架、教材目录、课例资源面板与连续滚动预览能力；不改旧 Vue2，不建立与本任务无关的通用资源管理系统。
- 现有课例查询强制关联 `biz_textbook_book` 与 `biz_textbook_section(kind='LESSON')`，不能把独立指南伪造为浙教版课次塞入这个关系。
- 指南需要独立的业务目录及权限语义；具体采用何种最小元数据结构由开发代理查实源码后说明，必要增量 SQL 纳入本专题，不能无关大改核心教材模型。
- 书架名称、菜单数据库记录、前端菜单排序辅助逻辑及阅读器入口统一；保留原路由和菜单相对顺序，避免改名后排序失效。
- 文件存储复用 `TEXTBOOK_ROOT` 及现有受鉴权资源服务，不放公开 `/profile/`，不把 GB 级资料打进 JAR 或前端 dist。
- 教学指南、整册设计、原件和所有派生预览必须单独执行教师侧鉴权，不因复用学生教材阅读接口而开放给学生。

## 整理与发布

- 来源只读；采用独立批次命名空间、稳定来源键、内容哈希和资源去向清单，支持重复执行、失败续跑和目标环境 ID 解析。
- 保留已有课例/资源 ID 与评价归属；同课同作者同内容不重复新增，跨作者不因物理文件复用而混并评价。
- 2026逐课文件优先，汇编仅按实际内容补齐并提供预览/原件下载；可确认映射的旧版明确标参考。Word/PDF配对须检查正文与哈希，不能仅凭文件名去重。
- 发布遵循 130 Linux/systemd/Nginx 现状，123 仅作跳板。`TEXTBOOK_ROOT/cases` 曾通过软链指向独立版本资源树，迁移前重新解析实际路径，先完整准备并校验新资源，再原子切换。
- 不覆盖旧资源树，不删除旧 release 或备份；回滚只恢复本次应用、资源指向、元数据和发布状态，不整库回灌覆盖新作业/成绩。
