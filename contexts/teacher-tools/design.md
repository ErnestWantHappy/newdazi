# 教师工具单页导航设计

## 页面结构

浏览页由搜索与吸顶分类导航、虚拟“常用推荐”、12 个业务分类组成。重点分类全部显示；次要分类只展示 `preview_limit` 项，展开动作不离开当前页。工具卡片保持紧凑四列布局，并展示访问条件标签。

分类定位区采用带图标的自动换行按钮组，重点分类使用主题色、次要分类使用中性色，不使用横向滚动。工具没有外部图标时，前端按名称、说明、标签和访问类型依次匹配编程、网络、AI、图片、文档、PDF、表格、音乐、评价、班级等语义图标，并配套 6 组柔和底色；无法识别时才使用分类默认图标。该规则只负责展示，不修改数据库内容，教研员仍可为单个工具配置外部图标地址。

管理页使用隐藏静态路由，由浏览页按钮进入。它提供分类表和工具表，不增加第二个侧栏菜单；排序使用显式数字，避免为低频维护场景引入拖拽依赖。

## 数据模型

- `biz_teacher_tool_category`：分类主次、默认展开、预览数、图标、排序和状态。
- `biz_teacher_tool`：名称、说明、URL、标签、访问/来源类型、推荐、排序和软删除状态。
- `biz_teacher_tool_category_rel`：工具与分类多对多关系。
- “常用推荐”由 `is_recommended` 动态生成，不复制分类关系。

目录接口一次返回启用分类及其工具和推荐列表；管理端使用独立权限提供分页维护。服务端与前端均只接受无 URL 用户凭据的 `http/https` 地址。

## 权限

| 能力 | 教师 | 教研员 | 管理员 | 学生 |
| :--- | :---: | :---: | :---: | :---: |
| 浏览目录 | 是 | 是 | 是 | 否 |
| 维护工具 | 否 | 是 | 是 | 否 |

接口同时校验权限字符串与角色，避免仅误配菜单权限就扩大管理边界。

## 内网课堂工具运行

图像识别、小学实验和网络仿真使用独立 NSSM 服务运行，分别监听 3001、3003、3020，并限制为域网络本地子网访问。网络仿真不再占用 3000，因为该端口已由 3011 信息科技基础检测后端使用；不得为恢复旧地址而迁移或中断 3011。

目录地址仍由 `biz_teacher_tool` 维护，运行端口变化必须同步初始迁移 SQL 和独立增量 SQL。每个服务使用独立工作目录和固定日志目录，启动类型为自动；上线验收至少包含服务状态、服务器本机 HTTP、客户端 HTTP 和实际页面渲染。

## 回滚

应用回滚切回上一后端/前端 release；三张新增表可以保留。需要数据库级回滚时使用发布前完整备份，不能在发布后产生新维护数据时直接覆盖。
