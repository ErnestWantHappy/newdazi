# 教师工具单页导航设计

> 2026-11-08 已随1.30.80发布130，迁移、服务重启与前端切换完成。[发布证据与回滚](release-20261108.md)。

## 页面结构（2026-11-06 起）

浏览页自上而下：

1. **搜索与筛选面板**（吸顶，窄屏改静态）：搜索框 + 全部/当前数量；“教学任务”一行 5 个任务按钮；“条件”一行学段分类、来源、访问条件；“已选”行逐项显示并一键清除。
2. **有关键词或任一筛选条件时**：只显示“搜索结果”或“符合条件的工具”一个结果区，隐藏个人常用、精选与分类。
3. **无任何条件时**：我的常用（含最近打开，空时一行提示）→ 教研精选 → 全部工具（按分类，可展开/收起）。

教学任务是“按用途找工具”，分类是“按学段/来源浏览”，两者分组展示，不混成一组按钮；点击任务按钮会滚动到结果区但不改分类展开状态。

## 搜索与排序

- 词表统一由后端目录下发：`biz_teacher_tool_term`（教师常用说法 → 工具）与工具自身 `tags`、分类名、任务名。前端不另设同义词数组。
- 匹配分级：0 = 名称或别名；1 = 用途说明；2 = 标签/分类名/任务名。多关键词按“全部命中”，多词命中不同层级时取最差一级（`scoreTeacherTool` 用 `Math.max` 取数值最大）。
- 目录接口返回“工具×分类”行（同一工具多分类各一行，附 `categoryNames`），前端 `mergeCatalogTools` 按 `toolId` 合并；推荐列表也并入同一集合，标 `recommended`。
- 排序：匹配层级 → 推荐顺序 → 工具排序 → `toolId`，同等相关性顺序稳定。
- 分类行先合并、推荐行后合并时，必须补回真实`recommendOrder`，不能保留分类分支的最大值占位；单测与正式精选DOM顺序均已核对。
- `filterTeacherTools` 同时应用关键词、任务、分类、来源、访问条件，返回统一工具数组。

## 个人常用与最近打开

- 存储：`localStorage`，键 `teacher-tools-favorites:<userId>`、`teacher-tools-recents:<userId>`；页面明确写“仅保存在当前浏览器”。
- 常用按加入时间倒序、新加入在前，已有序不因一次点击重排；最近打开最多 6 条，最近在前、去重，“我的常用”里最多显示 4 条且排除已收藏项。
- 收藏按钮的点击与Enter/Space键盘事件均隔离卡片打开；账号信息未加载时提示重试，不写收藏或报成功。回查目录时找不到的工具自然消失，不会绕过上架/分类/角色边界。
- 打开工具仍经 `openTeacherTool`（仅 http/https、无账号信息、`noopener,noreferrer`），浏览器返回有效窗口后才记录最近打开；返回null提示失败，不代表外部站点已完成加载。

## 数据模型

- `biz_teacher_tool_category`：分类主次、默认展开、预览数、图标、排序和状态。
- `biz_teacher_tool`：名称、说明、URL、标签、**检索别名 `aliases`（顿号分隔，随工具全量替换）**、**教学任务 `task_tags`（逗号分隔编码）**、访问/来源类型、推荐、排序和软删除状态。
- `biz_teacher_tool_category_rel`：工具与分类多对多关系。
- `biz_teacher_tool_task`：教学任务编码、名称、说明、排序、状态。
- `biz_teacher_tool_term`：别名词条（`term`、`tool_id`、排序），`(term, tool_id)` 唯一，工具物理删除连带删除。
- “教研精选”由 `is_recommended` 动态生成，不复制分类关系。

目录接口一次返回启用分类及其工具、精选、任务（含去重工具数）和全部别名；结果缓存 `business:teacher-tools:catalog:v2`（5 分钟）。管理写操作尝试失效缓存，Redis异常不再向前端报告已提交写入失败；异常时允许缓存最多5分钟后过期。管理端另提供 `/manage/tasks` 只读任务清单与 `/manage/tools` 分页维护，保存时返回 `taskNameText` 便于核对。服务端与前端均只接受无 URL 用户凭据的 `http/https` 地址。

任务编码必须存在于任务表，状态只接受约定值；新建/新增关联只能选启用分类，编辑可保留原有停用分类。迁移同时回填词表和工具`aliases`列，管理列表与搜索一致；词条回填与`insertTerms`统一`sort_order=100`。

## 卡片与图标

- 卡片：44px 图标容器（`object-fit: contain`，不裁切）、名称与用途最多两行换行、访问条件/来源/一个标签、右上角收藏按钮。
- `DIRECT`在筛选、卡片和管理页统一显示“直接打开”；图标传递`categoryCode`以应用分类色调。
- 无 `iconUrl` 时按名称、说明、标签、访问类型匹配语义图标与 6 组柔和底色；`iconUrl` 加载失败只回退语义图标，不请求第三方图标服务。
- 本轮不为所有工具配 Logo，也不使用来源不明的品牌图；教研发可在管理页逐个补充可信官方图标。

## 权限

| 能力 | 教师 | 教研员 | 管理员 | 学生 |
| :--- | :---: | :---: | :---: | :---: |
| 浏览目录 `/catalog` | 是 | 是 | 是 | 否 |
| 维护工具/分类、读取任务清单 | 否 | 是 | 是 | 否 |

接口同时校验权限字符串与角色，避免仅误配菜单权限就扩大管理边界。

## 内网课堂工具运行

图像识别、小学实验和网络仿真使用独立 NSSM 服务运行，分别监听 3001、3003、3020，并限制为域网络本地子网访问。网络仿真不再占用 3000，因为该端口已由 3011 信息科技基础检测后端使用；不得为恢复旧地址而迁移或中断 3011。

目录地址仍由 `biz_teacher_tool` 维护，运行端口变化必须同步初始迁移 SQL 和独立增量 SQL。每个服务使用独立工作目录和固定日志目录，启动类型为自动；上线验收至少包含服务状态、服务器本机 HTTP、客户端 HTTP 和实际页面渲染。

## 回滚

应用回滚切回上一后端/前端 release；新增两张表与两个列可以保留（旧代码不读取即无影响）。需要数据库级回滚时使用发布前完整备份；`sql/teacher_tools_search_v2.sql` 末尾附回滚 DDL，执行会丢失本轮别名与任务归属，必须先备份。
