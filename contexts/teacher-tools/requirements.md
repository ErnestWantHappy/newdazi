# 教师工具单页导航需求

> 2026-11-08 已上线130正式1.30.80；角色接口、浏览器24/24与发布更新158教师可见已验证，详见[正式验收](release-20261108.md)。

## 目标

在 Vue3 教师端提供一个高密度、单页面、可维护的工具导航。教师无需理解旧站结构，即可按小学、七年级、八年级、省平台及通用场景快速找到入口。

## 角色与验收标准

- 教师、教研员、管理员可浏览；学生无菜单且接口拒绝访问。
- 仅教研员、管理员可进入隐藏管理页并维护分类与工具。
- 一级菜单“教师工具”紧跟“教师首页”，保留平台原侧栏。
- 重点分类默认完整展开；次要分类默认预览 4 项，可在当前页展开。
- 搜索名称、说明和标签，搜索时自动显示全部匹配结果。
- 工具按用途显示有辨识度的语义图标和色彩；分类定位自动换行，不产生横向滚动条。
- 所有入口通过新标签页打开，并使用 `noopener,noreferrer`。
- 首次从 3005、80 根站、省平台导入，之后以本平台数据库为唯一维护源。

## 2026-11-06 查找路径优化（本轮范围）

| 教师任务 | 目标体验 | 验收口径 |
| :--- | :--- | :--- |
| 知道名称/常见说法 | 搜“压缩图片”“PPT”“配音”能命中正确工具 | 名称与别名优先，说明其次，标签/分类/任务最后；多关键词全部命中 |
| 只知道教学需求 | 5 个教学任务按钮（编程与算法、课堂实验、备课找资源、制作教学素材、班级事务） | 任务数量来自真实工具覆盖，不用空任务凑数 |
| 反复打开同一工具 | “我的常用”加入/移除，刷新后仍在 | 按账号隔离，存本机浏览器；卡片明确说明不跨设备 |
| 暂时想不起来 | “最近打开”辅助 | 仅浏览器接受打开后记录，弹窗被拦截不记录；不声称外部工具已成功使用 |

- 关键词或任一筛选条件生效时统一为一个结果区：同一 `toolId` 只出现一次，标题显示真实命中数，不再同时铺开精选和分类列表。
- 精选按推荐顺序展示；来源区分“原3005站”“原80根站”，浏览筛选、卡片和管理页统一称“直接打开”。
- 收藏要求账号信息已加载；鼠标和键盘收藏均不打开工具，未加载身份不得显示收藏成功。
- 管理端拒绝未知任务编码、非法状态和新选停用分类；编辑允许保留原有停用分类，别名在管理列表可见。
- 关键词、教学任务、分类（学段）、来源、访问条件共同生效；“已选条件”逐项可见并可一键清除。
- “没有匹配结果”与“加载失败”分开：加载失败给出重新加载，不显示成空目录。
- 原“常用推荐”改称“教研精选”，仍由教研员统一设置；“我的常用”是教师个人的，两者不混用。
- 下架、删除或目录中不存在的工具不出现在常用与最近打开中；服务端目录仍按原上架/分类启用/角色规则裁剪。
- 卡片只保留名称、一句用途、访问条件、来源和一个标签；图片完整显示不裁切，失败回退语义图标。
- 不推断教师任教学段并隐藏其他资源；学段/分类是筛选条件，不改变默认可见范围。

## 明确不做（本轮仍保留）

- 不嵌入 iframe，不同步旧站运行数据，不提供自动登录。
- 不做评分、评论、排行榜、复杂审核、自动巡检。
- 不把“可直接打开”解释为“免费”或“学生免登录”：访问条件只按 `access_type` 展示。
- 不自动删除疑似重复工具；同品牌不同功能入口由教研发核对。
- 本学期不新建跨设备个人偏好表（见 `tasks.md` 待确认项）。
- 不导入明文凭据、私人协作房间、循环入口、娱乐站、“科学上网”、高风险或明显侵权下载入口。
