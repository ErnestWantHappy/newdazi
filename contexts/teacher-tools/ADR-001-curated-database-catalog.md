# ADR-001：一次清洗导入，之后由本平台独立维护

- 状态：已接受
- 日期：2026-08-10

## 决策

旧 3005、80 根站和省学科平台仅作为首批内容来源。导入时去重并清理问题项；上线后，分类、推荐、排序和上下架全部保存在本平台数据库，不做抓取或定时同步。

浏览体验采用现有平台侧栏加单页吸顶分类导航，不复制 3005 的深色侧栏。重点分类展开，低频分类折叠，保证“全部有价值工具”与新手可读性同时成立。

## 原因与影响

旧站内容包含明文凭据、私人房间、循环入口和不适合教学平台的链接，直接镜像会把历史问题永久带入新系统。独立维护使教研员可审核每次变更，也避免旧服务下线或变更破坏教师入口。代价是外部链接可用性需要人工巡检，本轮不引入自动探测。
