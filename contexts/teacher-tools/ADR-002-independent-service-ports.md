# ADR-002：课堂工具使用独立服务与端口

- 状态：已接受
- 日期：2026-08-10

## 背景

小型网络搭建、图像识别和小学实验项目文件仍在 `10.52.1.123`，但没有统一的自动启动方式。原网络仿真使用 3000，而该端口现由 3011 信息科技基础检测后端占用；移动 3011 会扩大到无关系统并产生回归风险。

## 决策

保留 3011 的 3000 端口不变。网络仿真改用 3020，图像识别和小学实验继续使用 3001、3003。三个项目分别注册 NSSM 自动启动服务，日志写入固定目录；防火墙只在 Domain 配置文件下向 `LocalSubnet` 放行对应端口。

教师工具目录通过稳定 `source_ref` 更新地址。初始种子与正式库增量 SQL 同步维护，避免新环境再次导入旧端点。

## 影响与回滚

该方案隔离了三个课堂工具，不影响 3011、3009、3010、80 和 3005。代价是服务器新增三个长期服务和三个内网端口，需要纳入后续巡检。

回滚时停止并删除三个 NSSM 服务和防火墙规则，恢复网络入口文件，再按数据库备份中的目标行快照精确恢复目录 URL。禁止为回滚目录地址而覆盖发布后产生的全库数据。
