# ADR-004：使用随机令牌公开分享活动通知

日期：2026-09-02  
状态：已确认并实现，待数据库迁移和浏览器验收

## 决策

为每条活动通知生成 32 字节随机令牌，链接形如 `/public/research-notice/{token}`。数据库只保存令牌 SHA-256 哈希；支持 7 天、30 天和永久有效期，撤销或重新生成会使旧令牌立即失效。

## 边界

匿名接口使用专用 DTO，只返回标题、正文、活动时间、发布人、学校和发布时间。图片必须带同一令牌，并且其原始 URL 必须出现在正文 HTML 中；评论、资源、附件、云盘和接收人不在公开接口范围内。

## 原因与替代方案

随机令牌无需登录即可分享，同时避免暴露连续主题 ID。相比直接开放主题 ID，令牌不可枚举；相比新增访客账号，部署和使用成本更低。令牌哈希存储使数据库泄露时不能直接复用分享链接。
