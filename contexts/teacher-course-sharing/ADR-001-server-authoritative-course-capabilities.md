# ADR-001：课程管理能力由服务端投影

- 状态：已接受
- 日期：2026-08-27

## 背景

教师可能因负责某个已指派班级而看到其他教师创建的课程。旧页面无法解释共享来源，并无条件显示设计、删除入口；删除时又先检查作答历史，导致无权教师收到误导性报错。

## 决策

教师首页课程列表由服务端显式返回创建教师、可设计、可删除及禁用原因。共享课程只授予现有批改和成绩协作能力，不授予设计、删除能力；前端不得自行推断或扩大权限。删除校验顺序固定为“管理权 → 历史数据门禁”。

## 结果

- 权限展示与后端最终校验使用同一业务事实，减少误导和越权入口。
- 前后端必须配套发布；新增字段保持向后兼容，但旧前端不会展示共享说明。
- 后续若增加“共同编辑者”角色，应扩展服务端能力计算，不直接在前端放开按钮。
