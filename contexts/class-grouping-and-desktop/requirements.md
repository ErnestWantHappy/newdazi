# 班级分组与教师端学生桌面需求

> 状态：2026-09-02 第一轮需求已确认，评分、实时状态和协作异常处理仍在澄清；尚未开发。

## 目标

建立可以被课堂展示和在线协作共同使用的通用班级分组事实，同时提供接近机房座位视图的教师端学生桌面。

## 已确认需求

1. 每个班级可以保存多套可复用的分组方案。
2. 课程使用分组时生成课时分组快照，后续修改模板不应静默改变已开始的课堂。
3. 每个非空小组有且只有一名组长；系统默认选择学号最小者，教师可以更换。
4. 组长只用于视觉标记，不具有额外提交、编辑、审批或管理权限。
5. 教师端学生桌面是机房学生终端监控视图：以网格卡片显示姓名、在线/离线、终端 IP、组别和组长，并可进入该生协作轨迹；它不是人工点名或考勤入口。
6. 学生卡片支持自由拖动，但界面必须明确区分“调整座位”和“调整分组”两个模式。
7. 座位位置和分组成员关系是两个不同事实，普通座位拖动不能改变在线协作路由。
8. 通用分组不能直接复用物联网实验专用的 `biz_iot_group` / `biz_iot_group_student`。

9. 分组支持按组数平均分、按学号区间分和教师手动拖动三种方式。
10. 每个当前班级学生必须且只能属于一组；学生当前是否在线不改变组关系。
11. 首名学生进入协作房间后，活动使用的分组快照冻结；课中换组需要教师确认并写明原组、新组、操作人和时间。
12. 学生桌面同步显示统一课堂状态：未进入、已进入、作答中、已提交待批、已批改、退回重交；协作活动另显示在线/离线和最近活动时间，不显示成绩。

13. 学生登录后，任意学生端页面保持受认证在线连接即可视为在线；连续 60 秒无心跳则转为离线。
14. 同一学生多终端在线时仍只显示一张学生卡片，显示在线设备数；主卡展示最近活动设备 IP，展开后查看各设备。
15. 完整 IP 只对有当前班级管理权的教师和管理员显示；服务端记录自己观察到的客户端地址，不接受浏览器自报 IP 作为可信事实。
16. 默认按学号网格排列；教师可进入调整布局模式拖动，并按“教师 + 班级”保存个人布局。
17. 默认突出终端在线状态；工具栏可切换作业状态视图。点击学生卡片打开设备、在线时长、小组和协作轨迹抽屉。
18. 平台生成匿名设备标识；无法从普通浏览器可靠取得 Windows 计算机名时只显示设备编号和 IP，不伪造机位名。
19. 默认卡片显示小组颜色、名称和视觉组长；分组视图可把同组学生聚拢展示。

## 入口（已确认）

- 主入口位于现有“班级管理”页面，在“我管理的班级”每行增加“学生桌面”。该入口天然携带学校、入学年份和班级，且无需把现有单页面菜单重构成父子菜单。
- 教师首页当前课程/班级区域增加“学生桌面”快捷入口，携带当前课程和班级，便于上课时直接进入。
- 学生桌面不放入“教师工具”，也不从属于在线协作；在线协作只是桌面中的一种状态和轨迹来源。

## 明确非目标

- 不在学生桌面重复建设点名、迟到、请假或缺席流程。
- 不把“当前未在线”自动解释为缺席；签到考勤课继续作为考勤业务的唯一入口。
- 不远程控制学生电脑，不读取操作系统计算机名、窗口或屏幕内容。
