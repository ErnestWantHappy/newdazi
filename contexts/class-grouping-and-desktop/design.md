# 班级分组与教师端学生桌面设计草案

> 本文只记录已经确认的结构方向，不把下一轮尚未回答的问题写成最终方案。

## 领域拆分

- 班级分组方案：可复用模板，按学校、入学年份和班级归属。
- 分组成员：学生到小组的唯一归属；每个非空组一名视觉组长。
- 课时分组快照：课程真正使用的不可变或受控变更版本。
- 座位布局：学生卡片的行列或坐标，不决定学生所在小组。

## 交互原则

- 默认进入终端监控模式，学生卡片以在线高亮、离线灰显的网格呈现；IP 和最近心跳只对有当前班级管理权的教师显示。
- “调整座位”只改变卡片位置。
- “调整分组”才允许移动成员，并在保存前校验重复、遗漏、空组和组长。
- 调整模板不得自动改写已经生成房间的课时快照；需要同步时由教师明确确认。
- 分组生成支持平均、学号区间和手动拖动，保存前必须校验成员不重不漏；在线/离线状态不改变成员关系。

学生桌面不写考勤事实。在线状态来自学生端受认证的连接/心跳，不能代替现有签到考勤课；断网、设备故障或学生未打开平台只能解释为“离线”。

## 在线状态与 IP

- 新增独立学生在线 WebSocket，学生登录后的公共布局负责建立连接；不能复用只允许当前课程班级的课堂控制连接作为唯一在线来源。
- 握手阶段从服务端请求取得客户端地址。只信任配置白名单内反向代理写入的 `X-Real-IP` / `X-Forwarded-For`；后端端口被直接访问时忽略客户端伪造的转发头。
- 普通浏览器不能可靠读取本机局域网 IP 或 Windows 计算机名。页面显示的是平台服务端观察到的来源 IP；经过 NAT、VPN 或多级代理时可能只看到网关地址，界面名称应为“连接 IP”。
- 在线状态存入 Redis 并使用 TTL，30 秒心跳、60 秒离线；MySQL 只保存需要追溯的会话开始/结束摘要，不逐次写入全部心跳。
- 每个浏览器生成随机设备 ID 并保存于本地存储；设备 ID 只用于区分同账号多终端，不作为硬件身份或反作弊证据。

## 页面与入口

- 主路由建议为 `/business/classroom-desktop`，由班级管理行内按钮携带 `entryYear`、`classCode` 进入。
- 教师首页提供携带 `lessonId + entryYear + classCode` 的课堂快捷入口。
- 页面顶部提供班级、当前课程、终端/作业视图、分组筛选和布局编辑；主体为学生卡片网格，右侧抽屉承载设备和协作轨迹。
- 不把“班级管理”菜单改为父目录，避免破坏既有路由、菜单顺序和帮助中心教程；学生桌面权限作为班级管理的功能权限或隐藏路由授权。

## 与在线协作的关系

在线协作读取课时分组快照，把每个学生路由到本人小组房间。学生桌面和在线协作共享同一份分组事实，但座位坐标不参与权限判断。

首名学生进入后冻结活动使用的快照。课中换组通过显式命令改变后续房间访问，并追加路由审计；旧组内容和轨迹继续保留。
