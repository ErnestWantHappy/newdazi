# ADR-001：服务端观察在线状态，学生桌面从班级上下文进入

- 状态：已接受，尚未实现
- 日期：2026-09-03

## 背景

教师需要类似机房终端列表的学生桌面，显示全班学生在线状态和连接 IP。普通浏览器不能可靠读取本机真实局域网 IP或 Windows 计算机名；现有课堂 WebSocket 只服务当前课程控制，也没有可查询的在线状态读模型。

## 决策

1. 学生桌面是班级级终端监控，不承担点名、签到、考勤或远程控制。
2. 主入口放在现有“班级管理”的已管理班级操作列；教师首页按当前课程和班级提供快捷入口。不新增一级菜单，也不归入教师工具或在线协作。
3. 学生登录后的公共布局建立独立受认证 Presence WebSocket；任意学生端页面在线都算终端在线。
4. 30 秒心跳、60 秒无心跳离线。实时状态存 Redis TTL，不按心跳频率写 MySQL。
5. IP 由服务端从可信代理链和远端连接观察，页面称为“连接 IP”。不接受浏览器自报 IP；经过 NAT/代理时允许多个设备显示同一出口地址。
6. 同一学生多设备聚合为一张卡片，平台生成的随机设备 ID 只用于区分会话，不视为硬件身份。
7. 默认按学号网格排列；教师可调整并按教师+班级保存个人布局。在线视图和作业状态视图分开切换。

## 结果

- 需要新增 Presence 握手/处理器、Redis 在线存储、教师班级查询接口和学生端公共连接组件。
- 正式发布前必须核对 Nginx `/ws/` 转发头和受信代理配置，并使用真实机房学生机验证是否能观察到独立内网地址。
- 即使 IP 显示为网关地址，在线功能仍可交付；不得为满足界面效果伪造终端 IP 或计算机名。
