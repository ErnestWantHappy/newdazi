# 机位助手回环认领与课堂异机提醒

2026-10-14，用户已确认127.0.0.1:28123静默握手方案；130已发布1.30.50/助手0.2.3，正式学生认领及机房现场仍待验证，见[正式验收](release-verification.md)。

1. 未运行助手时保留“机位未关联 / 下载机位助手”；运行后自动探测，认领成功显示绿色机位与物理内网IPv4。
2. 换账号时按当前学生身份重新认领，不依赖前一个学生的登录令牌或特殊URL，不弹业务关联窗口。系统浏览器权限提示不能由网页绕过。
3. 大屏只能使用助手上报地址，不用HTTP/WebSocket连接IP补位；未识别显示灰色“未连助手”。连接IP可保留在Presence诊断层。
4. 教师在当前授权班级输入或选择机房，一键保存全部有效、无冲突观测；记忆该班级最近确认的机房，取消逐台命名弹窗。
5. 常用基准记录学生、机房、设备ID、确认时IP与机位名；IP或设备变化显示黄色“异机登录”，教师可单人更新或整班重存。
6. 缺席、过期、重复IP/同机冲突与占用保留基准不能自动覆盖；历史课堂禁止修改。告警用于核实，不自动认定盗号，不封禁或改变作品/成绩权限。

验收证据与现场限制见 [verification.md](verification.md)，协议取舍见 [ADR-005](ADR-005-loopback-claim-and-ip-baseline.md)。
