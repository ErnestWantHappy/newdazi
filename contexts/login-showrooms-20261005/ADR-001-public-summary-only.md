# ADR-001：固定公开摘要与内部详情分离

2026-10-05，状态：已接受（用户明确授权公开概览并要求登录后查看详情）。

现有教研主题VO含正文及分享状态，监管接口含内部ID和更详细统计，不能直接解除鉴权供登录页调用。新增两个固定数量、只读查询端点，SQL只查询摘要，Service再次投影公开字段。内部接口仍执行原角色、菜单及学校/班级范围校验。匿名接口不返回可用于详情跳转的业务ID或资源地址。

采用现有表、注解和依赖，无数据库迁移。代价是概览最多60秒延迟、活动主讲信息无独立结构字段时只能如实显示发布方。活动数量不足时保持真实空缺；接口异常在各展厅提供重试入口，不使用示例数据冒充真实记录。

2026-10-05正式1.30.28实施：两个摘要端点白名单及原详情业务401通过。只发布摘要，未扩大内部详情权限；证据见[正式验收](release-verification.md)。

## 2026-10-07 已接受的范围修订

用户明确选择保留当前真实教研图片公开展示，只统一校验主题、学校和作者有效性。因此早期仅两个摘要接口、不含图片ID的限制不再描述当前焦点图需求；focus-slides、activity-image、post-image沿用既有展示接口，内部详情继续鉴权，不新增任意文件读取。图片只代理原教研图片目录，不抓取外链。见 [核验记录](../bug-review-20261007.md)。修复已随130正式1.30.35发布，验证范围见[正式验收](../bug-review-release-verification-20261007.md)。
