# ADR-003：登录输入优先与导学单按需注册

2026-10-14，已实施，130正式1.30.48。

后续发布未保留入口拆分与图片优化，固定延迟15秒的轮播扩展也可能撞上输入。资源缩小改善启动，但不能单独消除输入期间的展厅渲染竞争。

采用既有Vue3、Element Plus与浏览器定时/空闲能力：唯一源码恢复WebP与VForm动态导入，相关路由确认前等待注册；输入、中文组合态、登录及选校期间暂停辅助展厅工作。迟到响应同样排队，图片分批扩展，展厅子树不依赖账号或密码。离开页面取消全部回调。

不改变认证、字段白名单、计分或数据库，保留错误/重试语义。生产构建强制执行登录测试和入口/资源校验，防止从历史构建重新发布错误版本。用户授权后清理无用副本，保留回滚、运行依赖与旧哈希静态资源。

代价：持续输入时辅助内容会延后，导学单首次进入仍需加载组件；真实机房环境须单独确认。验证和回滚见[本轮验收](../login-input-fix-20261014.md)。
