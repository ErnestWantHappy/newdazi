## 2. P0-B：诊断与导入治理

- [ ] 2.1 题库导入两阶段处理
  - 第一阶段解析、规范化、必填/枚举/重复校验；第二阶段事务写入。
  - 错误返回行号、字段和中文说明，限制明细数量。
  - 数据库异常只记录脱敏关联 ID，前端不返回 SQL/JAR/堆栈。
  - _需求：REQ-P0-03_

- [ ] 2.2 诊断分类
  - 为学生删除保护、班级范围校验等预期拒绝增加明确业务类别。
  - 未知 SQL/系统异常保持严重；历史事件读取时按新规则动态重算。
  - 补充当天 13 条严重、4 条导入异常、12 条慢事件的分类回归夹具。

- [ ] 2.3 日志路径治理
  - 发布前核对 NSSM `AppDirectory/AppParameters/AppStdout/AppStderr`。
  - 推荐 stdout/stderr 固定到 release 外稳定日志目录并配置轮转。
  - 验证重启后新日志写入正确位置，旧日志只读保留。

  - 整题模式清除旧分项；逐项模式沿用完整性/合计校验。

- [ ] 4.2 前端批改交互

- [ ] 4.3 总分锁定与快照

## 8. P2-B：学生终端桌面

- [ ] 8.1 Presence 连接底座
  - 新增独立 `/ws/presence`，学生公共布局登录后连接。
  - 握手解析登录态、学生学校/班级、随机设备 ID 和可信连接 IP。
  - Redis TTL 记录 30 秒心跳、60 秒离线，多设备聚合。

- [ ] 8.2 可信代理验证
  - 核对正式 Nginx `/ws/` 的 `X-Real-IP/X-Forwarded-For`。
  - 增加受信代理配置和伪造头测试。
  - 在同网段学生机实测是否获得独立 10.x/192.168.x 地址；若经过 NAT，页面如实显示共享网关地址。

- [ ] 8.3 页面和入口

  - 网格卡片、终端/作业视图切换、班级/小组筛选、在线设备抽屉。
  - 默认学号排序，教师调整布局后乐观锁保存。

- [ ] 8.4 容量与权限
  - 50 人单班、400 学生多班连接；心跳期间 MySQL 写入不增长。
  - 同校无负责关系、跨校和学生读取全班状态均拒绝。
  - _需求：REQ-DESKTOP-01_
