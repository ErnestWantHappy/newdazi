# 电子导学单部署说明

电子导学单包含教师设计与发布、学生断点填写、自动评分、数据看板、课堂 WebSocket 控制和可选教师机文件服务。

## 部署顺序

1. 备份目标数据库，在维护环境执行 `sql/guide_sheet_v1.sql`；脚本不删除已有表，可重复执行。
2. 配置后端环境变量并启动服务。
3. 构建并部署 `RuoYi-Vue3`。
4. 使用管理员、教师、学生账号分别验证菜单、发布、填写和评分流程。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `GUIDE_SHEET_AI_PROVIDER` | `deepseek` | `deepseek`、`doubao`、`qwen`、`zhipu` 或 `custom` |
| `GUIDE_SHEET_AI_API_KEY` | 空 | 为空时AI题自动降级为人工处理 |
| `GUIDE_SHEET_AI_MODEL` | 供应商默认值 | 可选模型覆盖 |
| `GUIDE_SHEET_AI_BASE_URL` | 供应商默认值 | 自定义供应商必须配置 |
| `GUIDE_SHEET_HELPER_ENABLED` | `false` | 是否启用教师机文件服务 |
| `GUIDE_SHEET_HELPER_PORT` | `5000` | 教师机文件服务端口 |

AI密钥仅保存在服务端环境中，不能写入数据库、前端存储或日志。教师机服务不可达时，保存、提交、评分和看板仍可使用，只有文件直传与作品展示降级。

## 安全说明

- 所有管理接口同时校验权限、学校和创建者。
- 学生身份、学校、班级均取自登录态，不接受客户端冒充。
- WebSocket 握手使用 `Admin-Token` Cookie，并校验学校、班级和角色。
- 功能分支历史中曾出现数据库密码和登录调试数据，上线前必须轮换相关凭据。
