# ADR-001：行政班不变，拓展班独立成员与不可变名单

日期：2026-10-30。依据：用户已确认双空间方向，并明确旧50班位于130、本轮直接本机代码开发。

使用原账号与学生档案，不新建学号。拓展班仅复用现有指派和题单班级载体，成员来自独立关系，界面不换算载体年级。

课时创建冻结名单；题单发布保存投放名单，新成员加入时补记其已获授权的发布题单。交接模型原列三张新表，但仅课时快照无法保留移出/归档后的题单历史分母，因此补充 `biz_extension_plan_member`；活跃访问仍查实时成员，历史统计查累计投放名单。这一补充不扩大到DATA_LAB或普通课程成绩。

space_pref之外持久化space_selected，区分默认regular与明确选择。题单创建后不换学习空间或拓展班，避免草稿编辑改变旧发布版本的授权归属。

旧50班登记和冻结不自动执行；需生产只读前检及逐人账号对应后单独迁移。本轮仅提供历史只读代码入口。
