# ADR-002: 初中物联网“方案 A”班级共享账号、易读口令与 Topic 隔离架构决策

## 状态
已采纳并实现（2026-08-20）

## 背景
初中信息科技课程包含物联网实验教学，学生在课堂上使用掌控板和 Mind+（SIoT 模块）连接 MQTT Broker 发送传感器数据并在平台进行可视化展示。
此前测试验证了掌控板直连标准 EMQX（`10.52.1.129:1883`）的可行性，原 SIoT（`10.52.1.123:1883`）作为回退链路保留。
在多班级、多小组并发的课堂环境下，需要既满足学生在 Mind+ 中输入简单、不频繁打断课堂教学节奏，又保证平台能清晰归属数据至班级与小组。

## 决策：采用“方案 A”

1. **班级统一共享账号与 6 位易读口令**：
   - 账号格式：`class_{deptId}_{entryYear}_{classCode}`（如 `class_169_2024_01`）；
   - 口令：6 位大写英文字母与数字组合，字符集为 `23456789ABCDEFGHJKMNPQRSTUVWXYZ`，剔除易混淆字符 `0, O, 1, I, L`；
   - 教师可在后台一键轮换口令；口令在数据库中以 AES-256-GCM 密文和 BCrypt 哈希持久化，不存明文，不暴露管理凭据。

2. **按学号自然升序自动连续分组**：
   - 教师设置每组人数（默认 4，支持 2 或自定义正整数）；
   - 系统按学号自然升序进行稳定数学连续划分（`groupNo = ceil(index / groupSize)`）；
   - 分组生成后持久化为关系快照（`biz_iot_group_student` 与 `biz_iot_class_config` 版本号递增）；
   - 重新分组弹出二次确认警示框，避免覆盖已有数据。

3. **Topic 规范与分层隔离**：
   - 格式：`county/{schoolId}/{courseId}/{classCode}/{experimentId}/group{groupId}/data`；
   - Broker 层面通过 ACL 限制班级仅可向其所属班级前缀 `county/{schoolId}/{courseId}/{classCode}/#` 发布；
   - 班级内不同小组通过不同的 Topic 区分，平台后端接收器根据 Topic 精确关联至 `groupId` 并记录消息与诊断事件；
   - 前端提示明确的业务隔离声明：“本班同学使用相同账号和课堂口令，不同小组使用不同 Topic。此为课堂业务隔离，非组间强安全隔离。”

4. **投屏与学生端体验**：
   - 教师端提供大字号高对比度“课堂物联配置卡”，支持投屏与打印；
   - 学生端提供专属面板，展示本班连接凭据、所在小组、专属 Topic、同组成员及“一键复制 Mind+ 配置”快捷按钮。

## 后果与收益
- **极大降低学生输入负担**：全班输入相同的简短账号和 6 位课堂口令，Mind+ 积木仅需替换专属 Topic；
- **架构健壮**：EMQX 管理 API 适配器与 MQTT 平台接收器优雅容错，单测与构建 100% 通过。
