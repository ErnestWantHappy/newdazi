# 操作题 Python 文件设计

复用 TEXT 附件类型，保留 file_extension=py，不新增表或修改历史数据。原文本接口返回原文件名，前端据此分流源码与运行入口。

教师批改预览组件显式开启运行按钮；学生作品预览只读源码。新增 POST /business/practical-attachment/{id}/run，先验证教师或管理员身份及附件读取归属，再读取服务器端原附件。浏览器只提交 stdin，无法替换待运行的源文件。

复用 judge0HttpClient 及既有 http 配置，隔离执行、禁网络。源码64 KiB、输入4096字符、CPU3秒、内存128 MiB、输出32 KiB，全实例同时最多2个批改运行请求。最多等待20秒轮询，失败释放配额，组件切换/卸载丢弃迟到结果。

不会生成判题提交或自动评分记录。调用已有 Judge0 服务，新增本任务后端类及前端组件，不增加依赖或环境变量。正式启用需要前后端共同发布和后端重启，当前尚未发布。
