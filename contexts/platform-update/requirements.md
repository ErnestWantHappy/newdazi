# 平台更新日志需求

## 目标

为教师和教研员提供可扫描的版本时间轴，记录平台已完成并对外可用的功能升级、问题修复和维护结果；管理员可修订发布内容。

## 规则

- 入口为独立一级菜单“平台更新”，不把更新记录混入帮助中心正文。
- 教师、教研员、管理员可查看已发布记录；仅管理员可新增、编辑、发布、撤回和转草稿。
- 记录字段只有平台版本号、实际发布时间、标题、更新说明和状态，不增加更新类型、影响范围字段。
- 版本号使用三段数字格式，例如 `1.0.0`。
- 历史记录可根据仓库真实 Git 提交时间整理；不展示未发布提交。
- Git push 不视为上线。AI 完成真实发布、探活成功后，才创建或发布一条用户可见记录。

## 验收标准

- 页面使用时间轴，按实际发布时间倒序展示。
- 版本号非法时后端拒绝保存。
- 教师和教研员无法调用管理员维护接口。
- SQL 可重复执行，菜单、角色权限和历史版本不会重复创建。
