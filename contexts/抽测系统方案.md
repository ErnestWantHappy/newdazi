# 象山县信息科技区域抽测系统 - 产品需求规格说明书

> **版本**: v1.1  
> **日期**: 2026-01-16  
> **状态**: 已按区域抽测 v1 决策收口

---

## 一、项目背景

每年象山县教育局需组织全县中小学校进行一次统一的信息科技学科考试，目的是：

1. 对各学校的教学质量进行评估
2. 形成全县学校排名
3. 为教育决策提供数据支撑

---

## 二、系统角色

| 角色         | 权限说明                                                             |
| ------------ | -------------------------------------------------------------------- |
| **教研员**   | 创建区域抽测、组卷、指派班级、设置评卷人员、审核成绩、查看分析、历史存档 |
| **评卷教师** | 批阅分配的操作题（匿名批阅，看不到学生信息）                         |
| **参考学生** | 参加区域抽测答题（打字/理论/操作），**无法查看区域抽测成绩和对错反馈** |
| **普通教师** | 仅在被分配评卷任务时看到“区域抽测评卷”入口，不可查看抽测结果         |

---

## 三、功能模块

### 3.1 教研员首页

新增专属菜单，包含：

- **区域抽测管理**：新增/编辑/删除区域抽测
- **评卷管理**：分配评卷任务、查看进度
- **成绩分析**：全县成绩查询与可视化
- **历史存档**：历年区域抽测数据查询

### 3.2 创建区域抽测

**基本信息配置：**

| 配置项   | 说明                                               |
| -------- | -------------------------------------------------- |
| 抽测名称 | 如"2026 年象山县小学六年级信息科技区域抽测"        |
| 学校类型 | 小学(1-6 年级) / 初中(7-9 年级) / 高中(10-12 年级) |
| 考试年级 | 根据学校类型显示对应年级选项                       |
| 作答时长 | 默认 40 分钟，开启区域抽测时可调整                 |

**组卷功能：**

- 从现有题库选择题目（选择题、判断题、打字题、操作题）
- 设置各题分值
- 支持固定顺序、随机排序、随机抽题三种模式

### 3.3 指派学校班级

**选择规则：**

- 系统自动显示对应类型的所有学校（如选择"初中"则显示所有初中）
- 显示该年级的所有班级
- **每所学校只能选择一个班级**参加考试

**界面示意：**

```
学校         班级（点击选择）
─────────────────────────────────────
滨海学校     [1班] [2班✓] [3班] [4班]
测试学校     [1班✓]
大目湾学校   [1班] [2班] [3班✓] [4班] [5班] [6班]
丹城二中     [1班✓] [2班] [3班] [4班]
...
```

### 3.4 考试状态管理

| 状态       | 说明                          |
| ---------- | ----------------------------- |
| **草稿**   | 初始状态，可编辑              |
| **已开启** | 学生可以答题                  |
| **已关闭** | 学生无法再提交/修改，等待评卷 |
| **已发布** | 成绩已审核发布                |

### 3.5 学生答题流程

**登录逻辑：**

1. 学生登录系统
2. 系统判断该学生是否在区域抽测参考班级
3. 如果在参考班级且抽测已开启且未完成：**自动进入区域抽测答题页**
4. 完成后或考试关闭后：恢复正常学校课程

**答题规则：**

| 规则          | 说明                           |
| ------------- | ------------------------------ |
| 个人限时      | 首次进入区域抽测答题页开始计时，刷新、退出、重新登录不重置 |
| 断点续考      | 中途退出，下次登录自动恢复已保存内容                     |
| 打字一次      | 打字题提交或超时后锁定，不展示重新打字按钮               |
| 操作题覆盖上传 | 截止前允许覆盖上传，学生端不提供自己作品下载入口         |
| 未提交按 0 分 | 操作题未上传默认 0 分                                  |
| 考试关闭      | 关闭后学生无法再提交/修改，系统自动提交未提交学生        |
| 隐藏反馈      | 学生端不展示分数、对错、正确答案、解析、错题或历史成绩   |

### 3.6 匿名评卷系统

**评卷人员配置：**

- 从现有教师账号中选择评卷老师
- 按操作题选择评卷教师，可设置每位教师批改份数
- 不填份数时，该题剩余答卷自动均分给已选教师

**评卷规则：**

- **随机分配**：学生答卷随机分配，不回避本校
- **匿名批阅**：评卷界面不显示学生姓名、学校
- **批阅方式**：查看 PDF + 按评分标准打分

**评卷入口：**

评卷教师登录后，如果存在分配给自己的任务，教师首页显示"**区域抽测评卷**"入口，点击进入评卷工作台。

### 3.7 成绩审核与发布

**流程：**

1. 所有操作题评卷完成
2. 教研员进入审核页面
3. 查看各学校成绩汇总、异常分数
4. 确认无误后点击"发布成绩"

### 3.8 全县成绩分析

**分析维度：**

| 分析项   | 说明                   |
| -------- | ---------------------- |
| 学校排名 | 按平均分排名的柱状图   |
| 分数分布 | 全县学生分数分布直方图 |
| 题目分析 | 各题正确率对比         |
| 导出功能 | 支持 Excel 导出        |

**排名数据表示例：**

| 排名 | 学校名称 | 参考人数 | 平均分 | 最高分 | 最低分 | 及格率 |
| ---- | -------- | -------- | ------ | ------ | ------ | ------ |
| 1    | 滨海学校 | 45       | 92.5   | 100    | 78     | 100%   |
| 2    | 丹城二中 | 52       | 89.3   | 98     | 65     | 96%    |

### 3.9 历史存档

- 查询历年区域抽测记录
- 查看历史成绩和分析
- 支持不同年份数据对比

## 四、数据隔离

区域抽测数据与学校日常课程数据**完全隔离存储**，使用独立的数据表：

- `biz_county_exam` - 区域抽测主表
- `biz_county_exam_question` - 区域抽测题目
- `biz_county_exam_class` - 区域抽测班级
- `biz_county_exam_answer` - 区域抽测答题记录
- `biz_county_exam_student` - 学生状态
- `biz_county_exam_grader` - 评卷分配
