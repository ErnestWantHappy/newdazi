# 学生实验工具 + 题目开放开关 —— 需求文档

> 版本：v1.1 · 创建：2026-08-22 · 状态：需求已确认（开关位=成绩页、推进自动复位、打字不加开关、常驻按年级+班级/全年级、面板先本节课后常驻）
> 说明：本专题只含学生实验工具+题目开关；站点运维与信息展示（129 监控、平台更新补录、Agent 词典、帮助中心配置、底部版权）见 `contexts/site-ops-and-info/`。
> 方向：教师少负担、课堂闭环；复用既有班级/课程/指派模型，不改核心权限模型。

## 1. 背景与问题

### 1.1 学生实验工具
上课时老师常往学生端下发网址（百度、实验工具、实验一/二/三链接等），目前无统一入口。
需求：学生端顶部导航栏新增「学生实验工具」按钮，点开弹出面板展示老师下发的网址，点击后新标签页打开。

### 1.2 题目开放开关
现状：学生登录即可见并完成打字/理论/操作题，存在提前把理论题、操作题交掉的问题。
需求：理论题、操作题由老师上课时「开启」后才对学生显示/可做；一班开了、二班没开互不影响。
打字题保持现状（课前热身，登录即可练），不参与开关。

## 2. 方案总览

### 2.1 学生实验工具 = 常驻工具 + 本节课工具
| 类型 | 配置位置 | 用途 | 生命周期 |
| --- | --- | --- | --- |
| 常驻工具 | 教师端「学生实验工具」菜单（独立页面） | 百度等长期网址 | 配一次长期有效 |
| 本节课工具 | 课程设计器内「本节课工具」面板 | 实验一/二/三 | 随课程走，上这节课才出现在学生端 |

学生端自动合并：面板先显示「本节课工具」（无则整组隐藏），再显示「常驻工具」。点击 `target=_blank` + `rel=noopener` 新标签页打开。

### 2.2 题目开放开关 = 班级 × 当前课程
- 开关挂在「正在给这个班上的这节课」（`biz_lesson_assignment`：entry_year+class_code+dept_id 定位当前课程行）。
- 老师开启 → 学生端 current-lesson 返回 open=true → 学生端显示并可作答。
- **课程推进（进入下一课）时自动复位关闭**，满足「推进后自动隐藏、免维护」；也可手动提前关闭。

## 3. 详细需求

### 3.1 学生端
- 顶部导航栏新增「学生实验工具」按钮，点击弹出面板：
  - 分组一「本节课工具」（有则显示，无则整组隐藏）；分组二「常驻工具」。
  - 每条 = 名称 + 网址，点击新标签页打开；http/https 均允许（内网 http 资源）。
- 理论题：老师未开启时学生端不显示理论区，显示提示「暂未开放，请等老师在课堂开启」。
- 操作题：规则同上。打字题始终显示。

### 3.2 教师端（常驻工具）
- 新增菜单「学生实验工具」（含「工具管理」子页）。
- 新增/编辑/删除/排序/启停：名称、网址、说明、适用范围。
- 适用范围按「入学年份（级）+ 班级」精确指定，支持多选班级；也可选「整个年级」（class_code 为空）。
- 交互风格复用现有 teacherTools 卡片/管理页面，但数据独立（不由教研员统一维护）。

### 3.3 教师端（本节课工具）
- 课程设计器内新增「本节课工具」区块，与「开启物联网」同级。
- 可新增/删除/排序若干条（名称+网址），随课程保存。课程的所有指派班级学生均可见。

### 3.4 教师端（题目开关操作位）—— 结论：放成绩查询页
用户倾向放成绩页，评估结论：**合适**。理由：
1. 教师从首页课程卡片点「成绩」进入时已带 lessonId+entryYear+classCode 且处于单选班级模式，开关区可直接显示，操作成本≈首页点一下+成绩页点一下。
2. 成绩页已有「课堂表现管理」区块先例（仅单选课程显示），开关区沿用同款交互，风格一致。
3. 课后仍需能控制（补做重新开启、提前关闭），成绩页天然适合。
- 若后续老师反馈不顺手，再加教师首页课程卡片「开题」快捷图标（V1 不做，避免卡片继续拥挤）。
- 页面表现：仅当「单选班级 + 单选课程 + 该课含理论/操作题」时，顶部显示「题目开放」卡片：理论题开关、操作题开关，即时保存；tooltip 说明推进后自动复位。

### 3.5 边界与防捣乱
- 学生接口只读；开关写操作校验教师角色+班级归属。
- 开关写操作校验：目标（entry_year, class_code, dept_id）的当前课程必须等于所传 lessonId，防跨班/跨课误操作。
- 工具网址非 http/https 时预览提示，但允许保存（内网用途）。

## 4. 明确不做（防鸡肋）
- 打字题开关（保持现状）；纯课程级开关（一班开二班关做不到，已排除）。
- 按作息表自动开/关（依赖课表，成本高）。
- 学生端工具点击统计（过度设计）。
- 与教研员维护的「教师工具」导航合并（用途不同）。

## 5. 成功标准
1. 学生顶部有「学生实验工具」→ 面板分组正确 → 新标签页打开。
2. 常驻工具按班生效：A 班学生可见、B 班不可见；全年级配置全可见。
3. 老师在成绩页开一班理论题 → 一班学生可见可做；二班仍不可见，打字题正常可用。
4. 老师推进一班课程 → 一班理论/操作题自动隐藏；未推进二班不受影响。
5. 学生调写接口 403；跨班操作 403；目标课程≠当前课程 400。

## 6. 2026-08-24 课程设计器初始开放规则

- 课程设计器必须明确询问教师：新指派班级是否默认开放理论测试题、操作题；默认均隐藏，教师按课堂需要开启。
- 初始选择只作用于本次新增的班级指派。编辑并保存已有课程时，已有班级各自当前开关不得被课程级默认值覆盖。
- 成绩查询仍是课中随时开关的主入口，卡片放在筛选区下方；操作题文案要明确包含文件作品和 Python 编程。

## 7. 2026-08-24 课程设计器紧凑展示规则

- “本节课工具”默认只显示一行摘要和配置入口；已配置时显示数量，详细网址列表进入配置后查看，不在主表单长期展开。
- 题目开放、物联网、在线协作等说明默认使用 tooltip 或按需展开，页面不再常驻大段教学说明。
- 电子导学单改为紧凑状态行和普通尺寸操作按钮，不再使用占据整卡的大按钮；不改变原有启用、模板选择和保存语义。
- 已选题目的“操作”列固定在表格右侧，常用移除/调整操作无需横向滚动才能看见。
