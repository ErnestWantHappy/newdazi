# ADR-002：未修改的本课工具保留原配置

日期：2026-09-10。状态：本地实现，未发布。

问题：设计器缺失展开状态变量；每次保存课程都重校验旧工具，历史不合规网址会阻断无关课程修改。用户授权本地修复，禁止修改正式服务器。

决策（用户后续确认覆盖最初严格校验方案）：前端对比加载时工具快照，仅改变时提交列表。后端缺省/null保留，[]清空，非空列表校验结构后事务替换。网址不完整、非网页协议或含内嵌账号信息只在设计器行内提示，不阻止保存；半填行保留、完全空白新行不提交。学生首页只给明确无内嵌账号信息的HTTP(S)地址生成href，其他配置保留名称并提示联系老师完善。沿用现有课程事务与管理权限，不猜测补协议、不检查网站在线状态。

取舍：配置能保存不代表错误地址自动变成可用地址；网址检查移至提示及点击边界，不再作为课程保存门禁。课程284具体网址未知，不能宣称已恢复其目标网站。

验证：以 PROJECT_CORE.md v3.54 顶部记录为准；旧5项严格校验测试报告已被本次提示方案测试替代。没有正式账号、真实数据库或外站链接可达性验证。

发布与回退：无SQL。本轮禁止发布。未来需要学生端点击防护先就绪，再启用后端保存放宽和教师端提示，或同一维护窗口配套切换；不得只发放宽校验的后端给无点击防护的学生前端，也不得只发省略工具字段的新设计器给旧后端。应用回退保持学生点击防护，因为已保存的待完善配置仍在库中；不清理或删除这些配置。禁止将本轮含未收口改动的完整构建直接发布130。
