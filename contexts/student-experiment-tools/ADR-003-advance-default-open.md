# ADR-003：课堂推进后默认开放题目

- 日期：2026-09-14
- 状态：2026-09-18 已从正式 JAR 核实推进默认开放逻辑存在，取代此前仅本地状态

2026-09-18 补充：正式 Mapper 的两字段均为1，服务 AUTO/MANUAL 共用 `advanceOneClass`；直接提取正式 SQL 在 MySQL 临时表验证推进双开、其他班级不变、重复推进无效。课堂大屏误读接口 `data` 导致显示关闭是独立前端故障，按实际顶层返回修正；不需要再次发布后端或批量开启存量班级。真实在用班级未被推进作测试。

原规则在切换下一课时关闭理论和操作题，与当前课堂期望不符。自动与手动推进继续共用原有事务及指派 Mapper，在更换课程时同时将两个开放字段设为 1。教师仍可在成绩页手动关闭；编辑课程仍保留已有班级开关，新指派仍采用设计器初始选择。不批量开启已经关闭的班级，不改变权限和课程推进条件。

无表结构或迁移 SQL。需后端重新打包资源、重启并配套前端提示更新。回退代码仅影响后续推进，不自动撤销已推进班级的开放状态。相关测试与待验事项见 tasks.md 的 2026-09-14 节。
