# 统一课程与学生删除

日期：2026-09-10。用户明确选择统一“删除”入口；仅本地修改，不操作正式服务器或真实数据。

- 教师首页、课程列表单删/勾选删、学生单删/勾选删/整班删，都支持存在成绩与作品的数据。
- 沿用 business:lesson:remove、business:student:remove。课程仍限创建者/管理员，学生仍限当前学校和教师可管理班级；共享课程可见不等于可删。
- 页面只提供“删除”，移除重复“彻底清除”按钮；确认框说明成绩、答卷、作品及不可恢复后果，取消不发请求。
- 删除题库引用不删除题库题目；文件仅清理无存活引用的独占文件。学生的多人共享协作文档、外部129存档、既有审计快照按原清除边界保留。
- 数据库清理在事务内，文件在提交后处理；失败不得先删文件；删除行数异常拒绝提交。
- 本轮不执行SQL、数据库删除、发布、服务器重启。真实MySQL数据副本回归尚需后续验收，不能用模拟通过冒充正式删除成功。
