# ADR-002：WebOffice 使用独立公网域名与窄路径网关（已被 ADR-004 取代）

## 状态

已被 ADR-003 取代。信息中心已提供现有平台域名 `xxkj.xsedu.net.cn`，用户决定复用该域名，不再申请 `weboffice-api` 子域名。

## 决策

1. 拟申请独立公网域名 `weboffice-api.xsedu.net.cn`，只承载 WPS WebOffice 服务端回调和文件传输，不承载平台登录或管理 API。
2. 公网 HTTPS 443 经信息中心 WAF/反向代理，按原始 URI 转发到内网 `http://10.52.1.123:3010`：
   - `/weboffice/callback/**`：仅 GET、POST；
   - `/weboffice/storage/**`：仅 GET、PUT。
3. 生产 3010 已按上述范围转发至本机 3009，并保留签名所需请求头。3009 不直接发布到公网。
4. 公网域名正式生效前，`COLLABORATION_ENABLED` 保持关闭，不配置虚假的公网地址或测试密钥。

## 理由

- WPS 云服务不能访问 RFC1918 私网地址 `10.52.1.123`。
- 使用独立域名便于单独配置证书、WAF、日志和下线，不扩大现有平台管理面的公网暴露范围。
- URI、请求体或签名请求头被网关改写会导致 WPS-2 校验失败，因此必须使用透明的路径转发。

## 影响

- 信息中心必须提供受信任 HTTPS 证书、公网 DNS 和到内网 3010 的可达性。
- 若信息中心分配了不同域名，只需同步修改 WPS 控制台回调网关和 `WPS_WEBOFFICE_PUBLIC_BASE_URL`，无需改业务代码。
- 免费测试阶段公网网关上传限制至少 6 MB、读写超时至少 300 秒；正式购买后如提高单文件额度，须同步调整网关限制。
