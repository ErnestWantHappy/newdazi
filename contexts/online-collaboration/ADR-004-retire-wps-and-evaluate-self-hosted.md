# ADR-004：停用 WPS，下一编辑器按免费自托管 PoC 决策

- 状态：已接受
- 日期：2026-08-14

## 决策

停止继续开发和部署 WPS WebOffice：前端不再显示教师/学生入口，不再保留直达编辑路由；生产 `COLLABORATION_ENABLED` 关闭；后端关闭时不返回学生历史房间并拒绝 WPS 回调。现有四张表、房间文件和版本暂不删除，作为迁移与回滚证据。

替代方案不直接进入正式开发。先在 CryptPad Integration API 与 Collabora CODE + WOPI 两条路线中只选择一个 PoC；当前推荐先验证 CryptPad，Umo/Yjs 不作为 Office 主引擎。

## 原因

WPS 正式容量收费并依赖其云端回调平台；教育内网域名不能被 WPS 公有云解析和访问。继续打通公网网关仍不能解决正式授权成本。

CryptPad 可在教育网内自托管并通过浏览器 API 嵌入，不需要第三方服务回调；Collabora 可覆盖 Office 三类文件但免费 CODE 不是官方生产版。两者均必须以真实教学文件和 200 人压测结果为准。

## 后果

- 普通课程、个人操作题上传、批改和考试不受影响。
- 历史协作数据保留，不再对教师和学生开放。
- WPS AppSecret 只保留在私密历史配置；生产停用后应从活动服务环境移除，备份不得提交 Git。
- 新 PoC 选型确认前，不新增数据库迁移和编辑器依赖。
