# ADR-001：平台持有协作房间和文件，WPS 仅作为编辑器提供方（已被 ADR-004 取代）

- 状态：已接受（PoC）
- 日期：2026-08-11

## 决策

首个在线协作 PoC 使用 WPS WebOffice 免费测试应用。课程按指派班级创建独立房间；平台保存文件、版本、用户和权限，WPS 通过标准回调读取与保存。业务层不把 WPS 文档 ID 写入课程或操作题核心表，而使用独立协作表隔离提供方细节。

保存采用 WPS 当前推荐的三阶段协议，不新接入已暂停维护的单阶段保存。AppID、AppSecret、公网回调地址和 Token 密钥必须外置。

## 原因

WPS 更符合学校现有 Office 使用习惯，免费测试应用可先验证真实多人编辑链路；平台持有文件能保持班级权限、备份和未来迁移能力。独立模型也避免今后更换正式 WPS、Collabora 或其他编辑器时重做课程与操作题。

## 代价

WPS 服务端必须访问公网回调和文件地址；当前纯内网服务器不能直接联机。免费测试限制也只能证明协议可行，不能证明全县容量和正式授权成本。
