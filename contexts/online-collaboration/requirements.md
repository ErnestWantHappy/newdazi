# 在线协作需求（当前 CryptPad，WPS 实施记录已归档）

## 当前实施目标（2026-08-17）

平台继续以课程、学校、授课班、教师、学生、文件和权限事实为唯一业务边界。教师为课程每个授课班创建一个独立 CryptPad 房间和一份起始文件副本；同班共享，跨班和跨校拒绝。学生只通过平台登录进入，不注册 CryptPad 账号。

### 当前验收标准

- CryptPad 固定版本 `2026.5.1`，服务目录独立于既有平台，禁止 `latest`。
- 平台后端统一使用 `CollaborationProvider`，当前生产 Provider 为 `CryptPadAdapter`，本地和单测可使用 `MockCollaborationProvider`。
- 后端必须校验平台登录、课程、学校、届别、班号、房间状态和链接对应关系；关闭房间后旧链接不能创建编辑会话。
- 房间会话密钥只保存密文；学生和教师获得的会话配置不能跨班复用。
- CryptPad `onSave` 回传文件时校验房间、文件类型、大小和预期版本；成功追加 revision，版本冲突拒绝保存。
- 主域名和 sandbox 域名使用可信 HTTPS；服务只暴露本机回环端口给 Nginx，管理端口不对外开放。
- 每日备份 CryptPad 数据和配置，备份写入 SHA-256，保留策略和回滚路径必须可执行。

### 已验证的服务器事实（2026-08-17）

- 扩展服务器 `10.52.1.129`：16 核、31GiB 内存、根盘可用约 453GB；CryptPad 运行于 `/srv/cryptpad`，固定镜像为 `cryptpad/cryptpad:2026.5.1`，容器端口仅绑定 `127.0.0.1:3000/3003`。
- `cryptpad-compose.service`、`cryptpad-backup.timer` 已启用；备份目录为 `/srv/cryptpad/backups`，已生成带 SHA-256 的 `cryptpad_20260817_092620.tar.zst`。
- 本机 Nginx 已配置两个 Host 的 HTTP/WebSocket 转发；服务器本机带正确 Host 的 `/` 与 `/checkup/` 返回 200。
- DNS 当前已指向 `10.52.1.129`；服务器本机 HTTP 正常，但从当前验收电脑访问 `10.52.1.129:80` 仍超时，网络/防火墙路径尚未放行。

### 2026-08-19 HTTP 临时运行决定

- 按用户明确要求，CryptPad 主域和 sandbox 域暂改为 `http://office.xsedu.net.cn` 与 `http://office-sandbox.xsedu.net.cn`，服务器直接使用 80 端口。
- HTTP 仅用于内网临时验收，账号、会话和文档内容明文传输；在恢复可信 HTTPS 前，不得宣称适合正式或公网使用。

### 2026-08-19 嵌入门禁修复

- CryptPad 实例的 `enableEmbedding` 已启用并经服务器接口复核为 `true`；之前的禁用提示来自 decree 文件损坏，不是 DNS、Nginx 或字体资源问题。
- 该修复只完成 iframe 初始化门禁；真实房间、多人协作、刷新保留和保存回平台仍需在机房浏览器完成验收。

### 当前不承诺

- CryptPad 官方未对本项目 200 人并发作容量保证；必须用真实 Word/Excel/PPT 文件完成后续容量门禁。
- 两个域名目前直接解析到内网服务器 `10.52.1.129`；HTTP 可作为内网临时入口，可信 HTTPS 和跨网段访问仍未完成。

> 2026-08-14：WPS 因收费和公网回调条件终止。本文件下方 WPS 条目仅作为历史需求，不再代表当前待开发路线；当前 CryptPad 以本节固定版本、权限边界、备份和网关门禁为准。当前产品目标仍是“每班独立房间、全班同文档、Word/Excel/PPT、多个学校、至少 200 人总并发”。

## 1. 目标

在现有课程与操作题之上增加在线协作空间：教师为课程选择一份操作题起始 Office 文件，按已指派班级各创建一个独立房间；同班学生进入同一份文档协作编辑，其他班级、学校不能访问。

本阶段只验证 WPS WebOffice 免费测试应用能否完成“打开、多人协作、保存回平台”闭环，不替代现有个人作品上传、批改或考试流程。

## 2. 用户故事与验收标准

### R1 教师配置课程协作

- 教师只能配置本人、本校有权编辑的课程。
- 可从课程内操作题的 `STARTER` 起始材料中选择一个 WPS 支持的 Word、Excel 或 PPT 文件。
- 开启后按课程当前指派的 `学校 + 届别 + 班号` 各生成一个房间；原始题库文件只复制，不被修改。
- 关闭后房间转为关闭状态，保留文件和版本，不物理删除。
- 免费测试版限制在界面明确提示：最多 5 个同时打开的不同文档、单文件 5MB、带测试水印。

### R2 学生进入本班共同文档

- 学生登录平台后，只能加入自己当前课程、自己班级的开放房间。
- 同一班级的学生取得相同 `fileId`，不同班级取得不同 `fileId`。
- 学生无需再次登录 WPS；平台签发短期 `X-WebOffice-Token`。
- 页面内嵌 WPS 编辑器，并提供“重新加载”和错误说明。
- 学生身份以平台现有 `biz_student` 学籍事实为准，不要求另行维护 `sys_user_role=student`；匿名访问仍拒绝，学校、届别、班号和当前课程必须全部匹配。

### R3 教师预览和监管

- 教师可查看每个班的房间状态、当前版本、文件大小、最后保存时间、最近回调结果。
- 教师可进入指定班级文档；PoC 阶段教师与学生均有编辑权限。
- 提供可复制的班级链接；链接仍要求平台登录和班级/教师权限，不是匿名公开链接。

### R4 WPS 文件回调闭环

- 实现 WPS 必需的文件信息、文件下载、权限、批量用户信息回调。
- 使用 WPS 推荐的三阶段保存：准备、申请上传地址、上传文件、完成通知。
- 每次成功保存生成递增版本，数据库和磁盘文件一致；失败保留旧版本。
- 所有 WPS 回调校验 `WPS-2` 签名、AppID、Date 时间窗和平台自签 Token。

### R5 可诊断性

- 未配置 AppID/AppSecret、回调公网地址、SDK 地址、文件超限或 SQL 未执行时，接口返回可操作的中文原因。
- 房间记录最近一次 WPS `X-Request-Id`、回调类型、成功/失败、时间和简短错误。
- 健康接口区分：功能开关、WPS 凭据、外网基础地址、存储目录是否可写。
- 外网基础地址必须实际解析到至少一个非私网地址；只解析到 `10/8`、`172.16/12`、`192.168/16`、回环或链路本地地址时，禁止初始化 WPS iframe，并向教师显示域名、解析结果和公网 DNS/NAT 处理要求。

## 3. 明确不做

- 不开发 WPS/Mind+ 类桌面软件。
- 不把全县所有班合并进同一个文档。
- 不把协作文档自动当作学生个人操作题答案或考试成绩。
- 不在 PoC 实现文档历史版本界面、评论审计、在线人数精确统计或 Collabora 适配器。
- 不绕过 WPS 免费测试版许可和容量限制。

## 4. PoC 完成定义

1. 后端、前端编译通过，SQL 可重复执行。
2. 未填 WPS 凭据时，教师端能看到清晰的配置诊断而不是白屏。
3. 填入免费测试 AppID/AppSecret、配置互联网可解析且可访问的公网回调并在 WPS 控制台开启回调后：两名同班学生打开同一房间可同时编辑，另一班打开不同副本，关闭页面后新版本保存到平台。
