# ADR-002：班主任工作台复用个人主页 3012 静态子路径

## 状态

已采纳，2026-08-15 已发布。

## 决策

将纯静态“班主任工作台”作为个人主页发布包中的独立子目录，正式地址为 `http://10.52.1.123:3012/tools/banzhuren/`。

源码项目仍保持独立；发布时把其静态文件复制到个人主页 `public/tools/banzhuren/`，不合并 Vue 代码、不共享数据。工作台继续使用浏览器本地存储。

## 理由

- 不修改共享 80 端口主站配置。
- 不新增 3013 端口、防火墙规则或常驻服务。
- 与个人主页共用静态 Nginx、release、备份和回滚流程。
- 其他项目可以使用稳定 URL 直接跳转。

## 后果

- 3012 发布时必须同时验证 `/` 与 `/tools/banzhuren/`。
- 工作台升级需要重新复制静态产物并发布新的个人主页 release。
- 回滚 3012 会同时回滚个人主页和班主任工作台版本，但不影响 3010、3009 或数据库。
