# 帮助中心与郑东旭个人主页需求

> 状态：2026-08-16 已实现并发布；帮助中心 v4 与个人主页 v6 已完成生产验收。

## 1. 目标

1. 学业测评平台增加面向教师、教研员和管理员的帮助中心。
2. 登录页与登录后页面统一显示开发支持署名；登录后所有角色可点击进入个人主页，但不增加悬浮动画。
3. 建设可独立部署、可被多个项目链接的郑东旭个人主页。
4. 个人主页突出教育工具开发成果，以科技感设计和成熟动效呈现，兼顾深浅主题与移动端。

## 2. 角色与访问边界

| 功能 | 管理员 | 教研员 | 教师 | 学生 |
| :--- | :---: | :---: | :---: | :---: |
| 左侧帮助中心 | 是 | 是 | 是 | 否 |
| 联系开发者 | 是 | 是 | 是 | 无帮助菜单 |
| 右下开发支持署名 | 是 | 是 | 是 | 是 |
| 署名可点击 / 悬浮动画 | 是 / 否 | 是 / 否 | 是 / 否 | 是 / 否 |

帮助中心前端路由只对 `admin / researcher / teacher` 加载；学生不依赖“隐藏样式”，而是在动态路由层不加入该菜单。

## 3. 帮助中心内容

- 顶部用一张清晰的课程设计真实页面大图呈现“教学练评闭环”，并说明平台用途与开发者，禁止再使用无法辨认的多张小缩略图。
- 教师实时检查学生、任教班级、题库与课程，按缺失项直接跳转。
- 教师从共享学生数据到学情分析的 6 步横向流程；每一步同时提供“打开功能”和“查看图文教程”。
- 图文教程使用接近全屏的多图长页；学生导入、班级管理、题库新增/导入、课程、学生作答、成绩分析、人工/AI 批改均使用对应真实页面截图。
- 学生模板必须带 `01 / 2025 / 01` 示例；班号只允许 01～10，601/602 等三位班号在上传前明确拒绝。
- 题库教程必须用树状分支区分“单个新增”和“批量导入”，说明四类题及操作题配置，并明确批量导入不支持操作题。
- 批改教程必须区分学情分析、人工批改、AI 批改，包含 Enter 快捷键、百炼实名认证/额度/API Key 和官方入口。
- 教师不显示教研员/管理员帮助，并保留百炼 API Key 配置说明。
- 教研员、管理员单独显示区域组织与治理指南。
- “联系开发者”按钮打开 `http://10.52.1.123:3012/`。

## 4. 个人主页内容

- 身份：郑东旭，象山县大目湾实验学校信息科技教师、教育工具开发者。
- 首屏不一次铺满 19 个工具；先重点展示 6 个代表项目，其余项目默认折叠。
- 精选项目与完整项目均保持一行一个，包含标题、说明、面向对象、运行环境、成果及操作入口。
- 6 个精选项目全部使用真实页面截图；截图统一为 1600×900，必须呈现可识别的真实功能内容，不得使用空白画布、空数据占位或登录提示遮挡；班主任工作台作为 3012 静态子站在线开放。
- 入口语义固定为“打开工具 / 抖音展示 / 网盘获取”，不混用演示与下载地址。
- AI 音乐工具显示演示账号 `zdx` 与密码 `123456`，不尝试跨站自动填写。
- 讲座、代表性获奖、学校与联系方式。
- 使用降低高光和过度磨皮的二次元数字形象；照片不是页面唯一重点。
- 深色/浅色主题、桌面/移动响应式；主题色使用深海蓝、冰青、靛蓝和香槟金，不使用大面积绿色。
- 桌面端以固定视觉画面配合滚动分段切换、文字和图片视差；移动端每个项目内嵌独立画面。
- 桌面端固定产品画面在导航下方可用视口内垂直居中；短屏幕不得遮挡导航或操作区。
- “讲座与荣誉”首页重点展示 6 项，完整档案按日期倒序展示 22 项，并按讲座培训、本人获奖、指导学生、论文成果和公开课筛选。
- 每项成果可打开证明材料灯箱；网站只发布处理后的 WebP 预览，不发布或链接原始 PDF。
- 本人姓名、学校、奖项、日期和公章可以公开；学生姓名、验证/群二维码、联系电话、身份证信息及其他第三方敏感信息必须遮挡。
- 联系方式包含电话 `19157727791`、抖音、工具主页及用户提供的微信二维码，不显示小红书。

- 3010、3012 均为 HTTP 200。
- 个人主页精选项目严格为 6，完整作品初始隐藏、展开后严格为 19 且每项独占一行；390px 视口无横向溢出。

- 登录页署名底部居中；登录后所有角色署名右下显示、可点击 3012 且无悬浮动画。
