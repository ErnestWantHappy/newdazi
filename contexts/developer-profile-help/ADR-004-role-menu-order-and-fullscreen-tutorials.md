# ADR-004：角色菜单排序与全屏多图教程

## 决策

教师和教研员的顶级菜单由前端在权限路由生成后按角色排序，帮助中心固定在末尾；不修改数据库菜单顺序、权限或二级菜单。六步总览保持横向，点击后使用全屏多图教程；题库和批改用树状分支表达不同路线。

## 原因

数据库排序会同时影响不同角色且扩大变更面；若依单菜单常以根路径 `/` 包装真实子路由，因此排序必须同时识别子路由路径和标题。全屏多图页能保留总流程的可扫读性，又能让新手看清每一步真实界面。

## 后果

- 新增顶级菜单时若未配置优先级，会保持后台相对顺序并排在高频业务之后、帮助中心之前。
- 学生导入模板和 601/602 防错先由前端实现并发布；后端同规则已经本机测试，但必须在可隔离 JAR 发布时再上线。
- 回滚只切回帮助中心 v3 前端 release，不涉及数据库或 3009。
