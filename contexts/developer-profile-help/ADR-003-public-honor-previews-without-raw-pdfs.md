# ADR-003：荣誉材料只发布脱敏预览，不发布原始 PDF

## 状态

已接受，2026-08-15 随个人主页 v6 实施并发布。

## 背景

个人主页需要展示讲座、本人获奖、论文、公开课和指导学生成果。原始材料版式不一，部分 PDF 不只是奖状，还包含参训名单、身份证尾号、手机号、学生姓名、二维码或其他人员信息。直接把原始 PDF 放到公网会扩大与履历展示无关的信息暴露面。

## 决策

1. 原始 PDF 和原始图片只作为本地制作来源，不复制到个人主页发布目录。
2. 每项成果生成一张 1440×960 WebP 公开预览，页面不提供原始文件下载链接。
3. 郑东旭本人的姓名、学校、奖项、日期和公章属于履历证明，可按原件展示。
4. 学生姓名、验证/群二维码、联系电话、身份证信息及其他第三方敏感内容必须在图像层遮挡。
5. 对只有名单而没有奖状的成果，使用“奖项信息卡 + 真实名单节选”，明确标注其为名单节选，不伪造成奖状。
6. 构建和发布验收必须检查 WebP 预览数量为 22、发布目录 PDF 数量为 0、浏览器 PDF 请求为 0。

## 影响

- 优点：保留真实证明感，同时避免把与个人履历无关的第三方信息公开；移动端加载也比原始 PDF 更稳定。
- 代价：新增本地预览生成和逐图视觉复核步骤；以后增加成果时必须先更新预览与隐私检查。
- 回滚：页面可回滚到上一版个人主页 release；原始材料从未上传，因此无需远程清理 PDF。
