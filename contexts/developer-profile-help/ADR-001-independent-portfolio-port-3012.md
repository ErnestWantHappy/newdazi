# ADR-001：个人主页使用独立项目与 3012 端口

## 状态

已采纳，2026-08-15 正式发布。

## 背景

个人主页需要被学业测评平台及其他项目共同链接，并拥有独立视觉、依赖、更新节奏与部署生命周期。把它放进 `RuoYi-Vue3` 会让作品站与业务后台互相耦合，也容易在平台发布时被一起覆盖。

## 决策

1. 源码放在 `D:\dmwprogram\zhengdongxu-portfolio`。
2. 采用 Vue3 + Vite + GSAP/ScrollTrigger + Lenis。
3. 服务器使用独立 release 根 `D:\program\zhengdongxu-portfolio\releases\`。
4. 复用现有 Nginx 进程，在 3012 增加独立静态站点。
5. 学业测评平台仅通过 URL 打开个人主页，不直接引用其组件或资源。

## 结果

- 个人主页可独立发布和回滚，不重启 3009。
- 其他项目可以统一链接 `http://10.52.1.123:3012/`。
- 多一个 Nginx 端口和防火墙规则需要维护；未来若配置域名，只需更换平台环境变量和 Nginx `server_name`，不必搬迁源码。
