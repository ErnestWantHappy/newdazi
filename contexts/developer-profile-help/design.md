# 帮助中心与个人主页设计

## 1. 架构

```text
信息科技学业测评平台 :3010
├─ 动态路由 /help-center
│  ├─ admin / researcher / teacher 可见
│  └─ 学生不加载
├─ 联系开发者 ───────────────┐
└─ 全局开发支持署名（全角色可点击、无悬浮动画）│
                              ▼
郑东旭独立个人主页 :3012（独立 Vue3/Vite 项目）
├─ GSAP + ScrollTrigger 动效
├─ Lenis 平滑滚动
├─ 深浅双主题
├─ 6 个精选工具滚动叙事 + 19 个完整作品
├─ /tools/banzhuren/ 纯静态班主任工作台
└─ 讲座 / 荣誉 / 联系方式
```

个人主页源码固定放在 `D:\dmwprogram\zhengdongxu-portfolio`，部署根固定放在 `D:\program\zhengdongxu-portfolio\releases\<release>\frontend`。学业测评平台只保存可配置链接，不复制个人主页源码。

## 2. 平台实现

- `src/views/help/index.vue`：按角色条件渲染；教师用现有 4 个只读接口做可容错的实时准备度检查，不新增后端接口或数据库表。
- 帮助中心首屏右侧使用一张课程设计真实页面大图；教师流程采用六个横向步骤节点，每个节点保留“打开功能 / 查看图文教程”。
- `tutorials.js` 统一维护流程和教程数据；全屏 `el-dialog` 用树状分支、粘性步骤索引、多张真实截图和快捷入口展开细节，避免缩略图过小。
- 菜单排序在权限路由生成后按角色执行，只排序顶级侧栏；排序键同时读取顶级路径、子路由路径和标题，以兼容若依单菜单的 `/ + child` 结构。
- 学生导入模板和上传前校验使用既有 `xlsx` 依赖在浏览器完成，避免为单纯模板防错发布含无关改动的后端 JAR。
- `src/router/index.js`：根级动态路由，按角色加载。
- `layout/components/Copyright/index.vue`：固定右下链接，所有角色可点击 3012，不设置 hover 或 transition。
- `layout/components/Settings/index.vue`：移除可关闭版权的设置，确保署名始终存在。
- 登录页沿用已发布的底部居中署名。

## 3. 个人主页视觉系统

- 深色基调：深海蓝、冰青、靛蓝与香槟金；浅色主题采用纸白、深蓝文字和克制的蓝金强调。
- 首屏：左侧主张与数据，右侧数字形象、双轨道和坐标信息。
- 工具区：桌面端左侧固定 16:9 画面，右侧 6 个案例各占约一屏；ScrollTrigger 根据滚动位置切换画面和进度，产品图本身不再做会造成裁切的放大或纵向视差。全部 19 个作品放入默认折叠的单列档案。
- 素材：6 个精选项目全部从真实站点重采集为 1600×900；展示层统一使用 `object-fit: contain`。网络仿真截图必须包含真实设备和连接，AI 音乐截图使用有歌曲数据的教师出谱页；微信二维码保留用户原始图片，通过 CSS 无损裁切展示。
- 动效：Lenis 平滑滚动、首屏入场、轨道旋转、ScrollTrigger scrub、图像视差、指针光晕；`prefers-reduced-motion` 时停用非必要动画。
- 移动端：隐藏桌面固定画面，在每个案例内部以 16:9 完整展示对应图片；导航压缩、单列内容、标题自适应，并在根级裁切纯装饰横向溢出。
- 桌面产品视觉列：使用导航下方的可用视口高度建立 sticky 容器并居中画面与进度；视口高度小于 760px 时回退到顶部安全定位。
- 荣誉首页：6 张 3:2 杂志式精选卡片，平衡本人获奖、讲座、公开课、论文和指导学生成果；卡片点击打开灯箱。
- 荣誉档案：在当前单页内渐进展开，不增加路由或依赖；22 项按日期倒序排列，筛选后保持单列时间轴和证明缩略图。
- 证明材料：本地脚本只读取原始 PDF/图片，统一输出 1440×960 WebP。学生姓名、二维码、电话等在图像层进行不可逆遮挡；正式发布包校验 WebP=22、PDF=0。

## 4. 部署与回滚

- 3010 与 3012 共用现有 D 盘 Nginx 进程，3012 使用独立 `server` 块和独立防火墙规则。
- 班主任工作台按方案 1 放入个人主页 `public/tools/banzhuren/`，复用 3012，不增加端口或防火墙规则。
- 每次部署创建新 release，不覆盖旧目录。
- 修改 Nginx 前备份配置，先测试候选配置，再替换正式配置、再次测试并 reload。
- 3012 失败不需要重启 3009，也不涉及数据库回滚。
- 帮助中心 v4 为纯前端 release；3010 失败时只需恢复 Nginx 中帮助中心 v3 的前端 root，不动 3009、数据库与 3012。
- 个人主页 v6 仍是 3012 独立静态 release；回滚只切换 3012 root，不修改 3010、3009、数据库或端口。
