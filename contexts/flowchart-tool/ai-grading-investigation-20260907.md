- 另发现历史版本关联风险：流程图补交通过 `upsertAnswer` 复用答案 ID，各次提交均保存该答案 ID；列表只以答案 ID、课程、题目关联提交，可能返回历史版本重复行。建议加当前答案 `FLOWCHART:<submissionId>` 引用精确约束；尚未修改，需构造补交数据验证。

## 推荐的最小修复方案

1. 保持文件版本字段原义，前端按题型选择流程图提交 ID 或文件版本 ID；缺失版本不匹配，历史版本不采用。
2. 流程图与 FILE 均恢复最新 AI 任务；保留已有状态、教师权限及批改期限检查。
3. 无预设分项时忽略自拟项，采用合法总分并保留总评、置信度和原始证据；有分项题维持完整性、重复项、分数上限及总分一致性校验。进一步补总分整数类型校验，避免 `asInt` 将小数截断。
4. 列表精确关联当前流程图提交，补测两次提交不重复、补交后旧建议不匹配。
5. 复用现有单份填分和批量采用；验证仅补未评分、覆盖审计与学生补交拦截。
