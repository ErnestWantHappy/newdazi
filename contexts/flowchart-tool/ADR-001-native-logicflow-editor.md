# 画程采用平台原生 LogicFlow 编辑器

状态：已接受（2026-08-30）

画程采用随现有 Vue3 前端一同构建和发布的 LogicFlow 图形底座，由平台 Spring Boot 后端负责课程权限、草稿、正式提交和批改数据；不直接嵌入公网 diagrams.net，也不在扩展服务器部署完整 draw.io。公网嵌入接入较快但依赖课堂外网，私有 draw.io 功能完整但会增加独立服务、iframe/CSP 运维和儿童受限交互定制成本；LogicFlow 需要自行建设产品界面，却能精确实现小学生精简工具栏、教师锁定元素和平台原有作业闭环，并且运行时不依赖外部服务。

## 后果

- Vue3 前端新增 LogicFlow 依赖，随平台前端制品发布，不增加独立运行服务。
- 平台拥有画程业务数据与权限边界，图形库只承担浏览器内编辑和渲染。
- 首期不承诺兼容 `.drawio` 文件，也不提供完整 draw.io 的专业绘图能力。
- 实施前仍需验证 LogicFlow 在平台当前 Vue 3、Vite 和机房目标浏览器上的兼容性及构建体积。
