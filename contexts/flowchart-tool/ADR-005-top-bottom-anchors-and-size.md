# ADR-005：普通图上下锚点与可选尺寸

日期：2026-09-23。状态：本地实现，未发布。

## 背景

课堂流程图通常纵向连接。普通节点四边均显示连接点会使连线偏斜；默认缩放步长和无节点尺寸持久化影响大图编辑。旧作品和判题不能中断。

## 决定

普通图只提供上下两个中线锚点，判断菱形仍为四个。加载旧普通图侧边锚点时转到上下，并让 LogicFlow 重新计算端点和折线。节点完整宽高仅作为 JSON 中的可选属性，旧数据不迁移；结构判题忽略尺寸。平行四边形按实际宽高重算点集，菱形半径在保存时转成完整宽高。画布按钮缩放使用固定步长与上下限，视图比例不进入作品。

## 影响与验证

前后端需配套更新，无 SQL。Chromium 实测锚点、连线、三种节点缩放、撤销重做、保存重开、PNG 导出；后端画程退回重交与结构测试通过。复杂旧折线路由仍需课堂样本抽查；旧成绩不自动重判。
