# 画程以版本化 JSON 作为作品真实数据

状态：已接受（2026-08-30）

画程以平台定义且带 `schemaVersion` 的 JSON 文档保存节点、连线、文字、坐标和题目约束，不以 PNG/SVG 图片或 draw.io XML 作为作品真实数据。教师出题图、学生自动保存草稿和学生正式提交分别保存各自版本；正式提交生成不可变快照，图片仅作为缩略图、导出或其他派生结果。这样既能恢复编辑和检查图结构，又避免把平台业务格式绑定到 draw.io，并延续现有操作题正式提交不可变、补交形成新版本的规则。

## 后果

- 画程 JSON 必须有平台自有的 schema 版本、大小上限、服务端结构校验和向后兼容策略，不能直接信任浏览器提交内容。
- 自动保存必须携带修订号进行并发控制，旧页面不得覆盖较新的草稿。
- 教师批改默认用同一画程组件只读渲染正式提交；预览图生成失败不得破坏原始作品。
- 首期不承诺 draw.io XML 双向兼容；未来如需导入导出，应通过显式转换器完成。
