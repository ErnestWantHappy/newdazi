## 3. Agent 词典（发布登记自动更新）

### 3.1 目标（已确认）
每次 AI 修改代码并部署上线到 123 服务器时，必须登记：时间日期、版本号、本次修改内容；平台更新页自动带出，不需要用户每次提醒。

### 3.2 机制（推荐已采纳）
1. 仓库登记单：新建 contexts/RELEASE_LOG.md，固定表格结构：日期 | 版本号 | release 目录 | 本次改动摘要 | 是否已写入平台更新。
2. AGENTS.md 硬性条款：任何部署到 123 的轮次，任务收尾清单新增两项：已登记 RELEASE_LOG.md（时间/版本号/改动）；已通过后台接口/管理页将本次更新写入 biz_platform_update（先草稿，确认后 PUBLISHED）。
3. 部署校验脚本 tools/check-release-log.ps1（轻量，可选）：发布切换前校验 RELEASE_LOG.md 有与本次日期匹配的新行，否则提示未登记。
4. 写入接口：复用现有 POST /business/platform-update（admin 权限）；AI 用管理员会话调用或幂等 SQL 亦可。
5. 平台更新页无需改代码（已有新增/编辑/发布 UI），只靠流程与登记单联动。
