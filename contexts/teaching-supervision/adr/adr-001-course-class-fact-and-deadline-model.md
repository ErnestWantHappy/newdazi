# ADR-001：课程班级事实与批改期限分表

## 状态

已确认，2026-07-28。

## 背景

`biz_lesson_assignment` 只保存班级当前课程，本机推进历史为空；已有大量历史课程班级关系只能从答案或课堂表现恢复。只建立期限和审计两张表会让监管历史事实长期依赖动态推断。

## 决策

新增课程班级事实表，并与期限主表、调整审计表分离。事实表保存曾经发生的课程班级关联及证据来源；期限表只保存含操作题班级的首次触发事实；动态批改数量实时计算。

## 后果

- 今后课程保存和推进必须同步维护事实表。
- 课程改派必须先关闭旧当前事实；课程删除必须在同一事务清理期限审计、期限和事实。
- 历史回填可区分当前指派、答案和课堂表现证据。
- 旧课程时间缺失时，监管查询可用事实证据时间归档，但不反写历史课程字段。
- 不改变当前指派唯一索引和学生当前课程语义。
- 多增加一张表和两个写入集成点，但换取稳定、可审计的监管事实。
