# 设计

2026-10-20已发布130正式1.30.53，见[正式验收](release-verification.md)。

- 学生文件上传区解除正式分数导致的上传禁用。暂存文件不触碰答案、评分或当前版本。
- 提交服务保留当前指派行锁、作品锁、答案锁和expectedVersionId校验。已评分文件无需RETURNED前置状态。
- 同一事务先将当前版本及其正式分数/分项归档，再写入新版本、NULL分答案和SUBMITTED状态；异常继续向外抛出，沿用rollbackFor=Exception。已评分但无当前版本的异常记录拒绝重交，避免无痕丢分。
- 已评分提交只确认一次清分；取消不提交。成功响应立即同步新版本、待批状态和空分，后续刷新失败仍明确提示已提交，不恢复旧分或误报提交失败。
- 文件作业总分沿用答案实时汇总，不新增成绩字段。未评分删除规则、流程图评分锁和教师纸卷导入覆盖确认保持。
- 无结构/业务SQL、新依赖或配置修改；已前后端配套部署并重启后端，仅执行发布登记SQL。回退应用不恢复已提交的新作品旧分；历史归档保留，不回灌整库。
