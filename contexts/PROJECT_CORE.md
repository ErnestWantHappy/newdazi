# 信息科技学业测评平台：当前核心事实

> 版本：v1.0  
> 更新：2026-08-20  
> 用途：新的 Codex、Claude、Gemini 或人工开发者的默认入口。只记录当前仍有效且已验证的事实；历史发布和排障证据见 `contexts/context.md`。

## 1. 先读什么

1. `AGENTS.md`：操作边界、验收顺序、远程授权和凭据规则。
2. 本文件：项目当前状态与不可违反的边界。
3. `docs/architecture/INDEX.md`：按任务进入相应架构文档和专题。
4. 仅在任务相关时读 `contexts/<专题>/`；与本文件冲突时，先核对代码、数据库或部署证据。

## 2. 系统与目录

| 层 | 当前事实 |
| --- | --- |
| 后端 | `RuoYi-Vue/`，Java 8、Spring Boot、RuoYi 3.9 Maven 多模块；`ruoyi-admin` 启动，`ruoyi-business` 承载业务。 |
| 前端 | 仅维护 `RuoYi-Vue3/`，Vue 3、Vite、Element Plus。`RuoYi-Vue/ruoyi-ui/` 是旧 Vue2，除非用户点名不得修改。 |
| 数据 | MySQL 为主，Redis 用于缓存、限流和分布式锁；MyBatis Mapper XML 是数据访问的重要事实来源。 |
| 迁移 | 新 SQL 放根目录 `sql/`，先备份、前检、执行、后检；不得把本机迁移成功等同于正式库已迁移。 |
| 文件 | `uploadPath*` 为业务文件，`backups/`、`output/`、`tmp/` 不能被当作业务源码或索引默认输入。 |

## 3. 角色与业务边界

- 平台角色：管理员、教师、学生、教研员。服务端权限校验是最终边界，前端隐藏不构成权限控制。
- 课程、答题、批改、学情是主业务域。新功能应复用既有用户、学校、班级、课程与权限模型，不新造账号或成绩体系。
- Python 刷题是独立业务域：不写 `biz_student_answer`，不改变课程成绩、课程推进或既有课程 Python 判题。
- 在线协作由平台持有课程、班级、房间、文件和访问权限；CryptPad 只提供受限编辑会话。
- 物联网是课程实验辅助，不重做 Mind+，不做考试和自动评分；浏览器不接触 Broker 管理凭据。

## 4. 当前外部集成状态

| 集成 | 已确认事实 | 当前风险 / 下步 |
| --- | --- | --- |
| Judge0 | Python 判题由后端通过私有 HTTP 调用；浏览器无 Judge0 地址或令牌。Python 刷题已完成正式迁移和发布记录。 | 尚未完成真实班级规模与高并发压测。 |
| CryptPad | 已采用 CryptPad Integration API，替代已退役 WPS 路线；平台对房间访问做学校、班级、课程与状态校验。 | 当前内网 HTTP 仅作临时验收；尚缺同班多人编辑、刷新保留、回平台保存递增和容量验收。 |
| EMQX / MQTT | 最新方案 A：EMQX 是正式目标 Broker，原 SIoT 保留为回退。班级账号、易读口令、学号排序分组、Topic/ACL 规则已写入当前代码和专题。 | 代码和本地验证完成，但正式平台 MQTT 接收器默认关闭，正式上线须重新核对环境、SQL、Broker 与真实硬件链路。 |
| WebSocket | 导学单、课堂和 IoT 都使用服务端 WebSocket；连接路径和鉴权见 `docs/architecture/INTEGRATIONS.md`。 | 改实时功能必须验证鉴权、断线和跨班隔离。 |
| LibreOffice | 用于 Office/PDF 转换和操作题预览，存在独立进程池、队列、健康巡检和并发参数。 | 生产参数与机器资源耦合，改配置必须按专项验收。 |

## 5. 环境与发布

- 本地：后端 `8080`，Vue3 Vite 默认 `80` 并代理后端。
- 正式平台：内网主机 `10.52.1.123`，后端 `3009`、Vue3/Nginx `3010`；发布以独立 release 目录切换，保留上一个 release。
- 扩展服务：`10.52.1.129` 承载 Judge0、CryptPad、EMQX 等独立服务。任何“运行中”状态均需在实际操作前重新探活，不能只相信文档。
- 密码、令牌、Cookie 和私密部署路径只允许在 `contexts/secrets.local.md`；不得出现在 Git、截图、日志或回复中。

## 6. 当前工作区与验证口径

- 工作区长期可能含未提交的多功能并行修改。开始任何任务先运行 `git status --short`，只在任务涉及的文件范围内工作，绝不 reset、覆盖或删除他人改动。
- 当前仓库中 IoT、Python、协作与平台更新都有未提交代码和专题资料；是否已发布、服务是否已切换，以本次实际探查为准。
- 可靠性优先级：当前代码和可复核数据库/部署证据 > 有日期的最新文档 > 历史会话/旧提示词。
- `contexts/context.md` 约 199KB，保留为审计证据。文件中多个“当前接力焦点”是历史快照，不再作为当前状态依据。
