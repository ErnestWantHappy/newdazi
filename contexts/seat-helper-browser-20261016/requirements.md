# 需求：静默启动与默认浏览器优先

2026-10-17已按用户重新授权合并发布130正式1.30.52，双端`20261017_seat_score_v1`、助手0.2.4；真实教师/教研员验证及更新130/PUBLISHED通过，学生与机房仍待验。见[正式验收与回退](../seat-score-release-20261017.md)。

2026-10-16，用户确认方案一，并确认正式域名为`http://xxkj.xsedu.net.cn`。

- Windows当前用户登录后自启，普通启动和重复启动不弹状态窗、不强制打开网页。托盘可主动查看状态或打开平台，桌面平台快捷方式仍主动打开网页。
- 同一安装包支持正式域名和`http://10.52.1.130`；不用特殊链接、不按浏览器重复安装。
- 已登录学生的网页自动请求本地助手。不同浏览器不同账号同时在线，Windows默认HTTP浏览器优先；无默认浏览器学生会话时其他浏览器可用。
- 默认浏览器停止学生检测后自动释放优先权；同浏览器换学生继续静默认领。其他浏览器不再反复抢占，也不显示重新下载。
- 不改变学校、学生、作品、成绩权限或教师常用机位基准；助手故障不阻断上课。
- 系统/浏览器权限弹窗、还原卡和同传环境需现场验证，不以开发机模拟代替。
