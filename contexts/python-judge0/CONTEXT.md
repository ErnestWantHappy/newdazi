# Python 在线编程与独立刷题

本上下文统一课程 Python 编程与独立刷题领域用语，避免把题目分类、使用位置和学生练习记录混为一谈。

## 语言

**Python 编程题**：统一题库中以 `practical/PYTHON` 表示、由 Judge0 判定程序输出的题目。
_避免：Python 独立题型、刷题专用题_

**课程 Python 题**：被课程选用并参与课程操作题成绩的 Python 编程题。
_避免：Python 第四题型_

**独立刷题**：不进入课程成绩和课程推进的日常 Python 练习业务。
_避免：Python 课程练习_

**系统题库**：平台维护、通过自动验证后供教师直接选用的 Python 编程题集合。
_避免：AI 实时题库_

**练习题单**：教师从 Python 题库选择一组题目，发布给一个或多个本人负责班级的独立刷题任务；选择全年级只是一次选中该年级全部可管理班级。
_避免：年级基础题单、班级加练包_

**删除题单**：无学生练习记录时彻底移除题单；已有练习记录时停止投放并归入已删除题单，保留可恢复的提交和学情历史。
_避免：把停止投放与清空学生数据混为一谈_

**题目快照**：题目加入已发布题单时冻结的题面、限制和测试点副本。
_避免：题目副本、历史题_

## 关系

- 一道 **Python 编程题** 可以成为 **课程 Python 题**，也可以被用于 **独立刷题**。
- **课程 Python 题**参与课程操作题成绩；**独立刷题**不写课程答案和成绩。
- **系统题库**中的题目必须先通过参考解法全测试点验证。
- 一个 **练习题单**可以发布给一个或多个班级；需要额外练习时创建另一个练习题单，不再引入第二种“加练”对象。
- 已发布题单通过 **题目快照**固定当时的题面和判题规则。

## 示例对话

> **教师：**“这道系统题能不能既放进课堂，又放进练习题单？”
> **开发者：**“可以。它始终是一道 Python 编程题；加入课程后是课程 Python 题，加入练习题单后属于独立刷题，不需要给题目维护‘适用场景’字段。”

## 已消除的歧义

- “Python 题在操作题下”只描述课程成绩分类，不代表独立刷题页面必须显示年级、学期和第几课。
- “AI 内置题目”指由 AI 辅助离线生产并经过自动验证的系统题库，不指教师在页面实时调用 AI 出题。
