# ADR-013：题单编辑串行与未完成实验隔离

日期：2026-09-21。状态：本地已实施，未迁移、未发布。

## 决策

同题单所有添加/编辑先在事务内锁plan主行；发布共享该锁，草稿和序号使用锁定读。MAX+1仅分配序号，不承担并发保护。删除关联不删除快照；同版本重加复用快照和测试点，克隆版本保留独立副本。

DATA_LAB目前未满足学生来源、教师班级、发布快照、统计和评分冲突要求，采用服务denyAll及/profile/datalab资源优先拒绝。普通题单移除动态实验配置依赖。不得单独移除门禁作为启用方式。

## 影响与验证

重新加入不会更新为题库最新内容，这是保护历史依据的保守语义。串行锁仅限制同题单编辑，不锁整个题库。无新依赖，无数据库执行或服务器操作；真实数据库锁行为尚待隔离库验证。

Worker、文件校验、新建表非空来源约束属于启用前准备，不构成完整实验权限或数据迁移。已有NULL来源必须先治理真实来源，不能填0或直接删记录。后续补齐业务闭环再另行审查开放。
