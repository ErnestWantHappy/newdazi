# ADR-015：Python 零基础 V3 采用现有表的幂等数据包

日期：2026-10-13  
状态：已接受；题库数据与应用候选已随 130 正式 1.30.46 完成发布。

## 背景

现有 V2 题库以中等题为主，不足以支撑小学五、六年级零基础学生循序练习。平台已经具备统一 Python 题库、测试点、Judge0、题单快照和学生练习流程，本次不需要新建题型或重构学生端。

## 决策

1. 复用既有三表，以 `PYV3-001`～`PYV3-100` 作为稳定外部题号，来源标记为 `python-system-v3`；不新增年级、学期、课次或适用场景字段。
2. 题面中的适用学段与解题提示放入既有说明字段；统一题目创建人使用唯一有效教师账号，系统来源与人员署名继续分离。
3. 由受控生成器产出五个每批 20 题的幂等事务 SQL。导入前拒绝外部题号占用、同名非 V3 题和创建人歧义；回滚前拒绝已有课程、题单、提交或进度依赖。
4. 正式数据导入不自动关联课程或题单。学生可见性仍由教师发布题单决定；数据维护本身不改变任何真实学生任务。
5. 系统推荐同时接纳 V2/V3 属于应用行为变更，必须随代码单独发布；仅导入数据时，教师仍可从统一题库手动选择 V3。

## 结果

- 无结构迁移、无服务重启、无前后端 release 切换。
- 可按题号重复执行和精确定位批次；已有业务依赖时回滚会失败关闭，避免误删学生数据。
- 130 正式由 130 道增至 230 道 Python 题；新增 100 道、340 点，Judge0 340/340 Accepted。
- 正式学生题单可见性仍需在未来代码发布时使用有效隔离账号补做，不以给真实班级临时发题替代安全边界。
