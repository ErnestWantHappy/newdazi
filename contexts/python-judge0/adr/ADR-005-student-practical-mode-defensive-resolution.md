# ADR-005：学生端操作题作答方式的防御性核验

## 决策

学生课程接口应直接下发 `practicalMode`。为兼容历史 DTO、缓存或旧发布包漏传该字段，Vue3 仅对作答方式为空的操作题调用平台后端的学生编程详情接口；接口成功并返回已启用 Python 配置时，页面才补为 `PYTHON`。任何失败都继续按 `FILE` 文件作品渲染。

## 原因

课程 270 的题目 1754 已是 `practical/PYTHON`，但学生端曾因缺少可用字段错误显示上传文件。由平台后端执行现有权限与题目关联校验，既能恢复编辑器，也不会把普通操作题猜成编程题或把 Judge0 暴露给浏览器。

## 后果

正常 DTO 不增加额外请求；只有异常数据会多一次受鉴权的 GET 请求。该兼容层不修改题目、课程、学生答案或成绩，后续彻底消除旧 DTO/缓存后仍可保留作为安全回退。
