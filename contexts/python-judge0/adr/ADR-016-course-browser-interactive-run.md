# ADR-016：课堂运行使用浏览器交互终端，计分保留后台 Judge0

状态：2026-11-02 用户确认；已随130正式1.30.66上线，真实学生桌面/390px交互验收通过，未代交成绩。

原课堂将 stdin 预先一次性传给 Judge0，只返回程序 stdout，学生看不到自己的输入，多个运行按钮也增加理解成本。

决定：课堂“运行”复用已有本站 Pyodide，在独占 Worker 内通过 JSPI/run_sync 等待学生回车；代码不改写，不重复执行以补齐输入。课堂界面仅保留代码、运行/停止、交作业、草稿和折叠历史。服务器交互会话路线暂不采用，避免新增长连接、运行容器和资源回收体系。

“交作业”继续使用原 SUBMIT、鉴权、测试点和最高分链路；浏览器结果不可信、不计分、不生成后端运行记录。旧 RUN/CUSTOM_RUN API 保留，独立题单与 DATA_LAB 不变。无 SQL、后端或新依赖，回滚前端即可恢复原模式。

代价：依赖支持 JSPI 的新版浏览器；基础解释器首次加载和整班内存需要机房验证；Pyodide 与 Judge0 环境不同，不保证外部包或平台特性一致。提示语仍参与正式 stdout 比较，本次不改变评分规则。

实现、测试和剩余限制见 [专题验收](../../python-interactive-20261102/tasks.md)。
