# ADR-010：练习题单物理删除与自然班名

状态：已接受并已正式发布（2026-08-22）。

## 背景

统一题单第一版对已有练习记录的题单采用归档恢复，教师端因此出现“已删除题单”；班级又直接展示 `entry_year`，产生“2024届1班”等不符合教学现场的名称。Python 题沿用统一题目表课程字段时还会显示年级 `0`、学期 `0`，系统来源标记也曾被误当成创建人。

## 决策

1. 教师确认删除练习题单后，一律物理清理题单完整依赖链，不保留归档列表、恢复接口或历史学情。数据库备份是唯一整体回退手段。
2. `entry_year` 只表示入学年份，语言上称“2024级”，不能称“2024届”。服务端以每年 7 月 20 日为学年切换点，结合学校学段计算绝对年级，统一生成“801班、901班、1201班”等自然班名；未来入学和已经毕业的范围不进入可选列表。
3. Python 题不使用统一题目表的年级、学期和课次字段，保存为空并在 Python 视图与编辑表单隐藏。
4. 所有 Python 题的创建人保存真实人员“郑东旭”。V2 系统题来源继续保存在 `biz_programming_question_config.create_by=python-system-v2`，推荐逻辑读取配置来源，不读取题目创建人。
5. 旧 V1 80 题没有历史保留要求。在精确依赖前检和整库备份后，连同课程/刷题关联、快照、提交和用例物理删除。

## 后果

- 删除操作不可从产品界面撤销，确认文案必须说明题单、提交和学情会同时删除。
- 已发布题单的“修改即复制新草稿”规则不变；只有显式删除采用物理清理。
- 班级标签由服务端统一下发，前端不得按当前年份或 `entry_year` 自行拼接。
- V1 数据回退只能恢复发布前整库备份；应用回滚不能恢复已删除数据。

本决策取代 ADR-009 中“有练习记录则归档并可恢复”的部分，其余统一题单和不可变版本决策继续有效。
