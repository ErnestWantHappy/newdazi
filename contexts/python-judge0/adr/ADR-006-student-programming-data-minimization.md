# ADR-006：学生编程接口最小化返回数据

## 状态

已接受，并随 `20260818_180512_python_judge0_student_experience_v2` 发布。

## 决策

学生编程详情只返回公开测试点需要展示的名称、输入和期望输出；隐藏测试点只参与服务端汇总。学生历史提交使用专用脱敏 DTO，不返回 Judge0 token、请求 IP、平台内部异常摘要或其他运维字段。浏览器只访问平台 Java 接口，不能直接访问 Judge0。

## 原因

公开样例是学生理解题目和运行结果的必要信息，但隐藏测试数据、Judge0 认证信息和平台内部错误会扩大泄露面并干扰学生判断。专用 DTO 能把学生体验字段与后端诊断字段分开，避免实体对象字段增加后被接口自动序列化。

## 后果

教师和运维仍可通过服务端日志、数据库和管理接口诊断判题；学生只能看到与自己题目和提交有关的最小信息。后续新增学生返回字段必须重新检查是否可能泄露隐藏测试、内部网络或认证信息。
