# ADR-008：Python 题库统一，使用位置由关联关系决定

状态：已接受并已正式发布（2026-08-22）。

Python 编程题继续保存在统一题库并以 `practical/PYTHON` 标识，不增加“课程/刷题/通用”适用场景字段，也不另建刷题专用题目表。同一道题是否用于课程或独立刷题，由课程题目关联或刷题题单关联决定；管理端通过独立 Python 编程题视图隐藏年级、学期和课次等无关字段。这样既允许一题多用，又避免教师维护一个会与真实关联关系冲突的冗余分类字段。

实现后果：Python 专用标题、知识点、无输入标记、验证状态和内容版本进入 `biz_programming_question_config`；其中可空唯一 `external_id` 仅用于系统题的稳定编号和幂等导入，不表达课程/刷题用途，教师自建题保持为空。保存 Python 题时统一题目表中的年级、学期、课次会真正置空。只有验证状态为 `VALID` 的题可建立课程或刷题关联；删除前必须检查两类关联及历史数据，不能用普通删除破坏引用。

正式库已导入 `PYV2-001`～`PYV2-120`，共 120 题、720 个测试点；真实 Judge0 全量验证 720/720 通过。旧 V1 题因课程 276 仍在使用而保留，但默认推荐和教师题单选择只使用 `VALID` 的 V2 题。
