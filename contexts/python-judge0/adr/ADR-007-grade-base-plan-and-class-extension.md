# ADR-007：年级基础题单与班级加练包分层

## 决策

独立 Python 刷题采用“年级基础题单 + 班级加练包”模型。基础题单在同一学校、学期、入学届别内统一发布；加练包只对选择的一个或多个班级追加题目，不能覆盖基础题。

## 原因

年级统一基础题为教师提供共同的教学基线和可比较的学情数据。完全按班级维护独立题单会产生大量重复配置，且无法解释班级间完成率差异。完全禁止班级差异又无法满足分层教学。

追加式加练保留两者：学生始终获得基础题，教师可以按班级进度补充练习；统计也可明确区分基础题与加练题，避免误导。

## 后果

学生可见题目由基础题与本班命中加练包合并得到，服务端必须校验学校、届别、班级和包状态。题单撤回或升级不能删除历史提交和进度，已发布题目需要具备可追溯版本。
