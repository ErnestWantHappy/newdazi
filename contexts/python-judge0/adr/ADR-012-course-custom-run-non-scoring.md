# ADR-012：课程 Python 自定义运行不参与成绩

## 状态

已接受，2026-08-24 随 v1.26.2 发布。

## 背景

课程内 Python 输入输出题原来只有“运行示例”和“提交判题”。学生能看到输入说明，却没有填写 stdin 的位置；把学生临时输入混入正式提交会污染隐藏测试、课程成绩和已有答案。

## 决策

1. 为 `no_input=0` 的课程 Python 题提供独立 `CUSTOM_RUN`。
2. 自定义运行只执行当前代码与学生输入，不设置期望输出、不访问公开或隐藏测试点。
3. 执行成功的终态为 `COMPLETED`，只返回实际输出、错误、耗时和内存；不产生分数，不写 `biz_student_answer`。
4. 输入以 `biz_programming_submission.custom_input` 持久化，限制 UTF-8 64KB；逐点结果使用保留 ID 0，显示为“自定义输入”。
5. “运行示例”继续使用公开样例，“提交判题”继续使用完整测试点并承担唯一的课程成绩写回职责。

## 影响

- 优点：学生可以调试真实输入；课程成绩语义保持单一；历史记录可追溯。
- 代价：提交表增加可空字段，前后端新增一种提交类型；客户端必须把 `COMPLETED` 视为成功终态。
- 回滚：旧应用可忽略新增可空字段；应用回滚不要求删除字段，必要时按版本删除平台更新记录。

## 验证

生产课程 279、题目 1883 使用输入 `123 456` 返回 `COMPLETED / 579 / score=null`；运行前后课程答案摘要一致。
