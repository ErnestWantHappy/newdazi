# ADR-014 DATA_LAB版本与访问边界

日期：2026-09-21；2026-09-22验收更新。状态：130正式1.30.23已迁移发布；替代ADR-013的临时DATA_LAB全拒绝。

实验使用浏览器Pyodide，不进入Judge0。以现有Python版本快照附加实验配置，固定数据文件、说明、代码和满分；新版本复制，旧快照复用。文件使用UUID且上传登记归属，图表通过受控资源接口核验提交所属学生或教师管理班级。学生提交身份取登录态，来源必须授权BASE_VERSION。

提交锁题单主行与发布协调，唯一来源不允许NULL，重交revision递增并清评分；教师评分需带所见revision。实验提交纳入完成统计，满分纳入通过统计。课程暂不支持实验，保存按题库真实模式拒绝。

Pyodide在Worker执行，运行30秒/加载180秒超时销毁并可重建；主运行库0.26.4、依赖、openpyxl、et_xmlfile和中文字体随前端本站提供，默认/pyodide/，可用VITE_PYODIDE_BASE_URL覆盖。Nginx为mjs提供JavaScript MIME。Worker仅隔离页面线程，不承诺网络安全沙箱。

先备份及隔离库验证v1/v2 SQL，再配套发布前后端；新表是题单SQL依赖。迁移发现旧NULL/重复来源或缺历史快照时拒绝自动修复。回退应用保留新增表列，不自动撤销学生数据。

证据：完整Java654通过/2跳过、Vue3构建、隔离MySQL真实账号上传到评分/重交、越权、4并发提交/克隆/加题均通过；130已备份迁移发布，正式教师页面、仅本站资产中文Excel/PNG/超时恢复通过。详见output/full-release-20260921/。限制：正式未代学生提交/评分，课堂与低配置整班压力仍需观察；成功重交旧图文件暂保留磁盘但不再有提交引用授权，后续按备份策略清理。批改列表未分页，较大班级需后续评估。
