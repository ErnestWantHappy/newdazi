# 压缩包检查规则

1. 支持 ZIP、RAR、7Z、TAR、TAR.GZ/TGZ 等；优先使用 `7z`、`unrar`、`bsdtar`，Windows 可复用 `tar.exe`（libarchive）。记录实际工具与版本。
2. 只列目录与读取文件内容，不执行 `.exe/.bat/.cmd/.ps1/.sh/.py/.url` 或其他来源程序。
3. 成员路径必须相对、无 `..`、无盘符、无绝对路径；拒绝符号链接和超大解压体积，异常压缩比列为安全风险。
4. 每个文件按魔数识别 MIME，计算 SHA-256，记录大小和修改时间；嵌套压缩包递归检查并记录层级。
5. DOCX 读正文/段落，PPTX 读页数/备注/媒体，XLSX 读工作表名，PDF 读页数和首段，图片读尺寸，音视频至少记录格式和大小；缺少时长库时明确写「未实测时长」，不猜。
6. `.url` 读取目标；只允许明确公网 HTTP(S)。`localhost`、`127.0.0.1`、10/172.16–31/192.168 内网段和用户磁盘路径标记 `<blocked>`，不得作为可点击资源发布。
7. 检出学生姓名、学号、身份证号、私人联系方式时，相关文件保留原包并写「需教师本地查看」，不拆成新的公开资源。
8. 运行库、缓存、日志、临时文件、安装包、`__MACOSX`、`.DS_Store` 不单独上架；技术清单留在检查报告中，教师可见说明不逐项罗列。
9. 无法安全解压、密码未知、损坏或截断时转 `PENDING_ARCHIVE`；不得按文件名伪造检查结果。
10. 教师可见「使用说明」只写包内有什么、怎么打开、需要联网或本地运行等必要提示；不显示 SHA-256、完整目录、内部程序清单和安全扫描明细，长度与优秀课例说明保持同一量级。

分类建议：DESIGN → SLIDES → WORKSHEET → TOOL → MATERIAL → ARCHIVE。`sort_no` 按分类基数和同批次稳定序号计算，重复执行不跳动。
