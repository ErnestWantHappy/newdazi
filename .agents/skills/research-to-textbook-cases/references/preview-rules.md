# 预览规则

- PDF 直接作为预览文件；Office 用 LibreOffice `--headless --convert-to pdf` 生成 PDF。
- 转换器使用独立 `UserInstallation`、独立临时目录、单进程和 180 秒超时，不占用正式平台转换池。
- 单个转换失败只影响在线预览，继续处理其他文件；报告必须写明原因，原文件仍可下载。
- 超过 120MiB 或预计超时的 PPTX/PDF 标记「下载后查看」，不拖垮服务。
- 图片和 100MiB 以内的 MP4/WebM 继续复用现有鉴权媒体接口；音频如接入，沿用教师 Cookie 鉴权、Range 和 MIME 白名单，超过 100MiB 提示下载后播放。
- HTML 只有自包含、依赖完整且确认安全时才走现有沙箱；需本地服务、外部模型或未知网络的页面保留在原包并说明。
- RAR/7Z/TAR 等压缩包本身不展开在线预览，提供原包下载、中文说明和已拆出的独立可预览资源。
- 不得把「转换请求已发起」记为预览成功；以实际生成 PDF 且 SHA-256 复核为准。
