## 1. 功能概览

### 1.1 模块定位

电子导学单是面向课堂教学的交互式表单系统，支持教师设计导学单、发布到班级、学生在线填写提交、自动/手动评分、课堂进度监控。

### 1.2 角色与功能矩阵

| 角色 | 功能 |
|------|------|
| **教师** | 创建/编辑/删除导学单、表单设计器拖拽设计、评分配置、发布/关闭、教师看板（进度监控）、数据导出、评分管理 |
| **学生** | 查看当前导学单、表单填写（支持断点续填）、文件上传、提交答案、查看评分结果 |

### 1.3 核心页面

| 页面 | 路由 | 文件 |
|------|------|------|
| 导学单列表 | `/business/guide-sheet-list` | `src/views/business/guideSheet/index.vue` |
| 导学单设计 | `/business/guide-sheet/designer/:sheetId?` | `src/views/business/guideSheet/designer.vue` |
| 导学单看板 | `/business/guide-sheet-dashboard` | `src/views/business/guideSheet/dashboard.vue` |
| 导学单预览 | `/business/guide-sheet-preview` | `src/views/business/guideSheet/preview.vue` |
| 学生端 | `/student/guide-sheet` | `src/views/student/guideSheet/index.vue` |

### 3.3 关键业务逻辑

#### 3.3.1 可见性过滤

- 列表查询仅返回**公开导学单（is_public='Y'）**或**当前用户创建的导学单**
- 详情接口对非公开导学单进行创建者校验

#### 3.3.2 发布校验

- 仅草稿状态（status='0'）可发布
- 表单内容（formJson）不能为空
- 必须至少指派一个班级

#### 3.3.3 classCode 处理

- 前端传 `"1班"`（带"班"后缀）
- 数据库存储纯数字 `"1"`
- Controller 层需 strip "班" 后缀

#### 3.3.4 学生端安全

- formJson 返回学生前需过滤敏感字段：`_scoringConfig`（参考答案快照）、`_aiApiKey`、`_aiProvider`、`_aiModel`、`_aiCustomUrl`
- 递归移除 widget 树中所有 `scoring` 属性

#### 3.3.5 进度查询

- 通过 `biz_guide_sheet_assignment` + `biz_student` LEFT JOIN `biz_guide_sheet_progress` 获取完整班级学生列表
- 包含未开始的学生（progress 表中无记录的学生）

#### 3.3.6 评分引擎

评分系统支持 **4 种评分方式**：

| 评分方式 | 标识 | 说明 |
|----------|------|------|
| 精确匹配 | exact | 学生答案与参考答案完全一致 |
| 包含匹配 | contains | 按关键词数量比例计分：(匹配关键词数/总关键词数) × 设定分值 |
| AI 评分 | ai | 调用大模型评分（DeepSeek/豆包/千问/智谱） |
| 人工批改 | manual | 不自动评分，需教师手动批改 |

**AI 评分机制：**
- 支持多供应商适配：DeepSeek、豆包（Doubao）、千问（Qianwen）、智谱清言（Zhipu）
- 评分线程池：核心 3 线程，最大 8 线程，队列 200，CallerRunsPolicy 背压策略
- 同一学生 5 分钟内对同一导学单最多调用 AI 评分 3 次，超限后转为人工批改
- 评分提示词采用关键词匹配分层评分：
  - 涵盖主要关键词意思正确 → 满分
  - 匹配部分关键词，意思基本正确 → 60%-80%
  - 匹配少量关键词，意思偏差较大 → 20%-50%
  - 完全不相关 → 0 分

**评分配置存储：**
- 正确答案通过 `_scoringConfig` 快照保存在 formJson 中
- 因为 VForm3 设计器会丢弃自定义 `scoring` 属性，需通过快照机制保存

### 4.2 VForm3 表单设计器集成

#### 4.2.1 依赖安装

```bash
npm install vform3-builds@^3.0.0
```

#### 4.2.2 main.js 全局注册

```javascript
import VForm3 from 'vform3-builds'
import 'vform3-builds/dist/designer.style.css'

app.use(VForm3)  // 全局注册 v-form-designer、v-form-render 等组件
```

#### 4.2.3 设计器核心配置

在 `designer.vue` 中：

- **标签页约束**：HomeTab 标签页设置为 `internal: true`，不可删除、不可移动、不可拖拽
- **组件添加**：遍历 HomeTab 的 tab-pane，找到 `options.active = true` 的活跃标签页，将组件添加到其 `widgetList`
- **初始化**：使用轮询等待 VForm3 就绪（100ms 间隔，最多 30 次），确保 `designerRef.value` 不为 null
- **约束保护**：`enforceHomeTabConstraints()` 函数持续检测并修复 HomeTab 约束违规
- **图片上传**：`fixUploadURLs()` 修复 picture-upload 组件的 uploadURL 为空导致的 404 问题

#### 4.2.4 自定义扩展组件「图片展示」

文件：`src/components/ImageAddWidget/index.vue`

- 注册方式：`app.component('image-add-widget', ImageAddWidget)` 在 main.js 中全局注册
- VForm3 集成：通过 VNode 树遍历 → FieldPanel → customFields 注入
- 即时机加载：MutationObserver 监听 `.designer-card` 容器中 `.panel-container` 的 DOM 出现，实现零延迟

## 7. 关键业务逻辑详解

### 7.1 导学单生命周期

```
新建（草稿 status=0）
  → 设计表单（VForm3 拖拽设计）
  → 配置评分（可选）
  → 发布（status=1）
  → 学生填写提交
  → 自动评分（可选）
  → 关闭（status=2）
```

### 7.2 表单 JSON 结构

formJson 是 VForm3 的标准输出格式，包含：

```json
{
  "widgetList": [
    {
      "type": "tab",
      "category": "container",
      "internal": true,
      "options": { "name": "HomeTab" },
      "tabs": [
        {
          "type": "tab-pane",
          "widgetList": [
            { "type": "input", "options": { "name": "field1", "label": "姓名" } },
            { "type": "radio", "options": { "name": "field2", "label": "性别" } }
          ]
        }
      ]
    }
  ],
  "_scoringConfig": { "field1": { "score": 10, "answerType": "exact", "correctAnswer": "张三" } },
  "_aiApiKey": "sk-xxx",
  "_aiProvider": "deepseek"
}
```

### 7.3 评分配置存储机制

- VForm3 设计器会丢弃自定义 `scoring` 属性
- 通过 `_scoringConfig` 快照保存正确答案（在 formJson 顶层）
- 保存和加载时使用一致的 ID 查找逻辑（`id || name || guid`）确保正确答案关联
- 处理嵌套容器内的字段需递归遍历 `widgetList`

### 7.4 学生端断点续填

- 学生每次切换页面时发送心跳（`/progress/heartbeat`）
- 心跳记录 `current_page` 和 `last_heartbeat`
- 下次进入时恢复到上次页码
- 支持 `save`（保存草稿）和 `submit`（提交）两种操作

### 7.5 进度看板数据获取

- 通过 `biz_guide_sheet_assignment`（指派班级）+ `biz_student`（班级学生）LEFT JOIN `biz_guide_sheet_progress`（心跳记录）
- 获取完整班级学生列表（含未开始的学生）
- **不能仅查询 progress 表**（仅有心跳记录的学生）

### 7.6 字符集排序规则

- 不同表之间 JOIN 的 VARCHAR 字段可能存在 collation 不匹配（utf8mb4_general_ci vs utf8mb4_0900_ai_ci）
- 需在 SQL 中显式指定 `COLLATE` 或执行 `sql/collation_fix.sql` 统一排序规则

## 9. 常见问题与注意事项

### 9.1 VForm3 设计器空白页

**现象**：首次进入设计页或从其他页面跳转后，VForm3 设计器显示空白。

**原因**：VForm3 初始化是异步的，`designerRef.value` 在组件挂载后可能尚未就绪。

**解决**：已使用轮询机制（100ms 间隔，最多 30 次）等待 `designerRef.value` 就绪后才注入 HomeTab 标签页。不要使用 `setTimeout(200)` 简单等待。

### 9.2 HomeTab 标签页约束

**关键规则**：
- HomeTab 标签页必须设置 `internal: true`，确保不可删除、不可移动
- 所有其他组件必须嵌入 HomeTab 的第一个 tab-pane 内
- VForm3 序列化/反序列化时可能丢失 `internal` 标记，需在 `enforceHomeTabConstraints()` 中检测并修复

### 9.3 classCode 前后端不一致

- 前端显示 `"1班"`（带"班"后缀）
- 数据库存储 `"1"`（纯数字）
- Controller 层需 strip "班" 后缀

### 9.4 评分快照（_scoringConfig）

- VForm3 设计器会丢弃组件上的自定义 `scoring` 属性
- 必须通过 `_scoringConfig` 快照在 formJson 顶层存储正确答案
- 保存和加载时使用 `id || name || guid` 组合查找逻辑

### 9.5 进度查询 JOIN 策略

- 教师看板 `getProgress` 接口需通过 `assignment + student LEFT JOIN progress` 获取完整列表
- 不能仅查询 `progress` 表（仅有心跳记录的学生，未开始的学生不在 progress 表中）

### 9.6 AI 评分限流

- 同一学生 5 分钟内对同一导学单最多调用 AI 评分 3 次
- 超限后自动转为人工批改（`manual`）
- 线程池使用 `CallerRunsPolicy` 背压策略，防止任务堆积

### 9.7 学生端 formJson 安全过滤

- 返回学生端前必须过滤 `_scoringConfig`、`_aiApiKey` 等敏感字段
- 递归移除 widget 树中所有 `scoring` 属性（包括 `widget.scoring` 和 `widget.options.scoring`）

### 9.8 路由与 Keep-Alive

- 导学单设计页路由需设置 `noCache: true`，确保每次进入都是全新状态
- 路由名称 `GuideSheetDesigner` 必须与组件 `<script setup name="GuideSheetDesigner">` 的 name 属性一致

### 9.9 数据库字符集

- 确保 biz_guide_sheet_assignment、biz_student、biz_guide_sheet_progress 等表的字符集排序规则一致
- 不一致时需在 SQL 中显式指定 `COLLATE` 或执行修复脚本

### 9.10 自定义组件「图片展示」

- 需在 `main.js` 中全局注册：`app.component('image-add-widget', ImageAddWidget)`
- VForm3 集成通过 VNode 树遍历 → FieldPanel → customFields 注入
- 使用 MutationObserver 实现即时加载，避免轮询延迟
